MS To Do Sync **不硬依赖** Obsidian Tasks，但会解析 Tasks 风格的日期与优先级 emoji。若你同时使用 Tasks 插件做查询与看板，请注意元数据在行内的顺序。以下是详细介绍：

## 1. 为何注释不能放在行尾 emoji 之后
Tasks 从任务行**末尾向前**识别日期、优先级等；遇到无法识别的内容就停止。若写成：

```markdown
- [ ] 修水槽 #GTD/home 🔽 🛫 2026-09-28 <!-- mtd:id=mtd-xxx -->
```

则 `🛫` / `📅` 等可能不被 Tasks 查询识别。

## 2. 插件采用的兼容顺序
写回时，机器注释放在 **标题与标签之后、Tasks emoji 之前**：

```markdown
- [ ] 修水槽 #GTD/home <!-- mtd:id=mtd-xxx --> 🔽 🛫 2026-09-28
```

1. Tasks 仍可从行尾读到日期与优先级。
2. 本插件仍可通过正则解析 `mtd:` 注释。
3. 旧版落在行尾的注释，在下次同步写回时会迁到正确位置。

## 3. emoji 含义（与 Tasks 对齐）
1. `📅`：截止日期（due）
2. `⏳`：计划日期（scheduled）；本插件默认映射到 To Do 的开始日
3. `🛫`：开始日期（start）；本插件可解析
4. `⏫` `🔼` `🔽` 等：优先级

>备注：公开 README 若仍把 `⏳` 笼统写成「开始日期」，请以本教程与 Tasks 语义为准。

## 4. 实用建议
1. 让日期、优先级留在行尾侧；不要在它们后面再追加普通说明文字。
2. 标签可以出现在 emoji 之后（Tasks 允许），但插件默认写回常把标签放在注释前。
3. 用 Tasks 查询验证：`has due date` / `starts on or before today` 等，确认同步后的行仍命中。
4. 不要手删 `<!-- mtd:… -->`；需要停止同步时用插件菜单。

## 5. 未安装 Tasks 时
1. 仍可正常同步；emoji 字段由本插件自行解析。
2. 查询面板、看板等 Tasks 专属能力不可用，但不影响与 Microsoft To Do 的双向同步。
