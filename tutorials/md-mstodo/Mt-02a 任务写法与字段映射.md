插件按 Tasks 风格的 emoji 字段解析任务行，再映射到 Microsoft To Do。写法固定后，双向改日期、优先级、完成状态才会稳定。以下是详细介绍：

## 1. 最小可同步行
```markdown
- [ ] 买牛奶 #mtd-sync
```

保存或同步后，行内会出现机器注释（阅读视图隐藏），例如：

```markdown
- [ ] 买牛奶 #mtd-sync <!-- mtd:id=mtd-xxxxxxxx -->
```

若同时有日期或优先级，注释会落在**标签附近、Tasks emoji 之前**，例如：

```markdown
- [ ] 买牛奶 #mtd-sync <!-- mtd:id=mtd-xxxxxxxx --> 📅 2026-06-20
```

>备注：注释位置是为了兼容 Obsidian Tasks（Tasks 从行尾向前解析；注释若在 emoji 之后会截断日期）。不要手删 `mtd:id`，否则映射会断。

## 2. 字段对照表

| 你在 Obsidian 写的 | 在 To Do 中的表现 |
|---|---|
| `#mtd-sync`（或你改的命名空间） | 准入同步；`#标签/子标签` 可走路由 |
| `📅 2026-06-20` 或带时间 | 截止日期 |
| `⏳ 2026-06-18` | 计划日期（Tasks scheduled）→ To Do 开始日 |
| `🛫 2026-06-18` | 开始日期（Tasks start；插件可解析） |
| `⏫` / `🔼` / `🔽` | 高 / 中 / 低重要性 |
| `- [/]` | 进行中 |
| `- [x]` | 已完成 |

## 3. 完成与删除的区别
1. 在 To Do **勾选完成**：Obsidian 同步为 `- [x]`，默认**不会删行**。
2. 在 To Do **永久删除**任务：才走设置里的「删除行为」（删行 / 仅取消同步 / 保留行）。

## 4. 进行中状态
1. 把 checkbox 写成 `- [/]`，可表示进行中。
2. 与 To Do 的进行中状态双向对应（以当前版本字段映射为准）。

## 5. 不建议的写法
1. 不要在同一行塞入与任务无关的、跟在 emoji 后面的自由文本（Tasks 会停扫）。
2. 不要把同步标签打在非任务行上。
3. 不要手动改 `mtd:id` 的值；停止同步请用云图标菜单或相关命令。
