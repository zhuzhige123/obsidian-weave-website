登录之后，先确认「同步谁、同步到哪」，再写第一条带标签任务。范围设对了，才不会误扫模板或推到错误列表。以下是详细介绍：

## 1. 打开同步范围
1. 打开 **设置 → MS To Do Sync → 常规**。
2. 找到分组 **同步范围**。

## 2. 同步命名空间（标签）
1. 默认命名空间为 `mtd-sync`（任务行写成 `#mtd-sync`）。
2. 带 `#mtd-sync` 或 `#mtd-sync/子标签` 的任务才会准入同步。
3. 设置里填写时**不要带 `#`**；插件会按命名空间匹配子标签。

>备注：未打标签的任务永远不会同步。可用命令「同步当前任务行」给单行自动加标签并建立映射。

## 3. Obsidian 主同步列表
1. 设置项 **Obsidian 主同步列表**：填写 Microsoft To Do 中的列表名称（默认常见为 `Obsidian Sync`）。
2. 该列表专门与 Obsidian 双向同步；仅本列表及下方「专用同步列表」中的任务会入站写入库。
3. 请保证 To Do 里存在同名列表，或允许插件按名称使用/创建（以实际版本行为为准）。

## 4. 主列表入站默认笔记
1. 设置 **主列表入站默认笔记**，例如 `Microsoft To Do/Inbox.md`。
2. 当你在主同步列表里新建任务、且备注未写 page 定位时，插件会把任务追加到该笔记（不存在时自动创建）。

## 5. 排除文件夹（可选）
1. 在 **排除文件夹** 中加入模板目录等路径。
2. 这些文件夹下的 Markdown **不会**被扫描同步标签，避免示例任务被推上去。

## 6. 写第一条任务并检查
1. 打开任意笔记，写入例如：

```markdown
- [ ] 复习第三章 #mtd-sync 📅 2026-06-20
```

2. 保存，或按设置在「离开笔记时 / 停笔后」触发自动同步；也可在命令面板执行 **同步当前笔记中的任务**。
3. 打开手机或桌面 Microsoft To Do，在主同步列表中确认任务出现。
4. 在 To Do 勾选完成后，等待拉取或手动 **拉取远程任务更改**，Obsidian 对应行应变为 `- [x]`。

>备注：第一次建议用命令手动推一次，确认通道畅通后再依赖自动同步。
