设置页分 **常规 / 账户 / 关于**，界面语言可跟 Obsidian 或固定中英文。本节按分组说明「改什么、数据放哪」。以下是详细介绍：

## 1. 界面语言
1. **常规 → 界面**：可选自动 / English / 中文。
2. 只影响本插件设置与部分提示文案，不改变你笔记正文语言。

## 2. 同步范围与路由
见 `Mt-01b`、`Mt-03a`：命名空间、主列表、入站默认笔记、排除文件夹、子标签路由表。

## 3. 自动同步与远程拉取
1. **自动同步时机**：离开笔记 / 停笔延迟 / 仅手动。
2. **停笔延迟、标签行延迟**：减少边打字边推送。
3. **登录后自动同步**：连上账户后立刻推一批。
4. **增量同步间隔（分钟）**：从 To Do 拉取更改的频率。
5. **自动同步时通知**：后台推送成功是否弹提示。

## 4. To Do 关联与删除行为
1. 备注回链、关联资源、停止同步时是否清理远程回链。
2. 入站后是否移除 To Do 路由头。
3. **To Do 中永久删除任务时**：删 Obsidian 行 / 仅取消同步 / 保留行不变——与「勾选完成」无关。

## 5. 账户与高级
1. **登录 / 退出登录**；**登录帮助**对照常见失败原因。
2. **高级**：Azure 客户端 ID、租户。个人账户一般保持租户 `common`、客户端 ID 留空。

## 6. 数据放在哪里
1. **建议随库同步（Vault 内）**：Markdown 任务、备注、子任务——它们是笔记内容。
2. **插件目录 / secretStorage（通常不随笔记手抄）**：登录令牌、同步索引等运行状态。换设备后重新登录即可。
3. **网络**：仅通过 Microsoft Graph 传输已映射任务相关字段；**不会**上传整库笔记到第三方。

>备注：完整隐私与条款以插件仓库说明为准。不要把密钥、`.env`、refresh token 提交到公开 Git。

## 7. 关于页
1. 查看插件名称、版本、插件 ID（`ms-todo-sync`）。
2. 文档、反馈问题、联系邮箱等入口。
