The free tier covers everyday reading, five-color highlights, thoughts, excerpt re-highlight, bookshelf, bookmarks, and progress. Premium support adds timeline, precise positioning, paragraph mode, vocabulary marking, reading lists, and more—one-time purchase (per terms) to support long-term development. Details below:

## 1. What’s Free
1. Multi-format reading, TOC navigation, page-turn and continuous scroll.
2. Five-color highlights, thoughts, auto insert / copy, screenshot tool.
3. Excerpt summary card list.
4. Bookshelf multi-view, import scan, progress, current-page bookmarks, reference reading points.
5. Canvas bind and write nodes (per current software tiers; if entry shows a lock, follow prompt).
6. Export templates and built-in presets, public API (for other plugins—not everyday buttons).
7. In-reader tutorials, selection search / AI entry (AI needs separate configuration).


## 2. What Premium Adds
1. Excerpt timeline, full-bookshelf timeline.
2. TOC density bar, chapter colored dots.
3. Bookshelf reading lists.
4. Precise bidirectional tracing.
5. Regular reading translucency gradient, paragraph reading, immersive fullscreen.
6. Vocabulary marking.
7. Export whole-book / whole-chapter excerpts, chapter Markdown with marks.
8. Footnote popover preview.


## 3. How to Activate
1. Open reader settings **License**.
2. Enter a standalone EPUB Reader activation code.
3. If the main Weave plugin is installed and activated, license can inherit—no duplicate code needed.
4. License page shows source (Weave vs reader), sharing status, and expiry.
5. Purchase and redemption paths follow in-app notes and `PREMIUM_TERMS.md` (including community promotion redemption when offered).

> Note: Activation may contact the license service—see privacy section. Device limits per About page and terms.

## 4. Privacy and Network
1. Reading, rendering, excerpts, and backlinks default to local—Vault body text is not uploaded proactively.
2. Bookshelf and backlinks enumerate Vault paths locally; activation code copy and excerpts use the clipboard.
3. Activation may submit activation code, email, device fingerprint summary, etc. to the license service.
4. AI sends selected text to third-party endpoints you configure.

> Note: Full text in plugin repo `PRIVACY.md`. Do not send confidential material to the AI panel.

## 5. Font and Background
1. Font and size follow Obsidian **Settings → Appearance**.
2. Background follows the current theme—change theme to change reading background.
3. The reader does not ship a separate skin system.


## 6. FAQ

**Why don’t excerpts stick?**  
They must be written to Markdown, Canvas, or Weave Deck with traces. Momentary highlight alone is not enough. See `Er-02a 摘录笔记工作流`.

**Do I need Weave?**  
No. Reader-only Markdown notes work fine. Install Weave for spaced repetition, vocabulary list, and main-plugin license inheritance.

**Do excerpts sync across platforms?**  
Yes—sync the Vault. Do not rely on syncing plugin cache folders only. See `Er-04b 阅读器设置与数据同步`.

**Is it a subscription?**  
Reader premium is one-time purchase (activate once, long-term use per terms)—not monthly subscription.

**Who to contact for issues?**  
Try in-reader **Tutorials** first. You can also email the developer (public docs). **About** in settings lists community and changelog links.
