A reading plan generates dated task lines from the TOC. Copy and paste them into any note so Weave Review **Important schedule** can recognize and advance them. Good for splitting a book across calendar days without locking scheduling inside the reader. Premium support. Details below:

## 1. Open from the TOC
1. Open a book and show the sidebar **TOC**.
2. Open the menu on a chapter.
3. **Add to reading plan**: build a plan starting from that chapter (per dialog).
4. **Generate reading plan from this chapter**: schedule from here through later TOC entries—good for long books in segments.

> Note: Without premium you are told this is locked (UI may say **Important schedule**). Without Weave Review you can still paste task lines into notes; recognition and the schedule view need Weave Review Important schedule.

## 2. Configuration
Common options in the dialog:

1. **Start date**: which day the plan begins.
2. **Set a daily time**: optional fixed clock time; then pick **Daily time**.
3. **Interval (days)**: how many days between sessions (1 = every day).
4. **Chapters per session**: how many chapters per day (or session).
5. **Skip weekends**: whether to skip Saturday and Sunday.
6. **End mode**:
   - **Through end of TOC**
   - **At most N chapters**
   - **At most N days**
7. For the N-chapter / N-day modes, fill the matching limit.

The preview task block updates as you change options.

## 3. Copy into a Note
1. The preview shows a summary (count, start → end dates).
2. Click **Copy** to put all task lines on the clipboard.
3. Open any Markdown note and paste where you want them.
4. If the current config yields no tasks, the preview says empty—adjust date, interval, or end mode, then copy again.

> Note: The reader emits pasteable task text; it does not force a single plan file. Put lines in a reading journal, schedule page, or topic note.

## 4. vs Incremental Reading
1. **Reading plan / Important schedule**: calendar “which chapters on which day,” tasks living in notes.
2. **Incremental Reading**: send chapters into an IR queue and calendar deep-reading rhythm. See `Er-04c 与 Weave Review 制卡、增量阅读、AI 联动`.
3. Use either, or both TOC entries—calendar tasks vs reading-point queues.

## 5. Common Prompts
1. **No book open**: open a book before generating from the TOC.
2. **No chapters to schedule**: empty TOC or nothing after the start chapter—try another chapter.
3. Copy failed: select the preview text and copy manually.
4. Generate failed: close the dialog and retry after the TOC has finished loading.
