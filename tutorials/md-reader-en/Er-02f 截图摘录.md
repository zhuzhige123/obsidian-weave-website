Screenshot excerpts suit content you cannot cleanly select: illustrations, complex layout, cross-page tables, comic panels, and more. You can box a region on a page, turn pages to continue capturing, and save as an image file or embedded link. Details below:

## 1. Open the Screenshot Tool
1. Open a book.
2. Open **Screenshot tool** from the top bar or menu.
3. When enabled, drag a selection on the page.
4. Turn it off again when done so normal text selection is unaffected.

> Note: Screenshot tool works with auto insert: with automation on, results follow current note or Canvas rules.

## 2. Save Mode
**Save screenshot as image** appears in the menu or toolbar.

1. **Save as image file (on)**: Writes the screenshot to an image file in the Vault—reference in notes with `![]()`.
2. **Save as embed link (off)**: Writes into the current note as an embed link; exact format follows insertion result.
3. You can also copy the image to the clipboard and paste elsewhere.

> Note: For long-term archive and reusing the same image in many places, saving as a standalone file is clearer.

## 3. Continue Across Pages
When one page is not enough, turn pages while capturing.

1. Box the needed region on the current page.
2. Turn the page and box follow-up regions (per on-screen prompts).
3. When finished, write to the note or save images together.


## 4. vs Text Selection Excerpts
1. Text selection: Searchable text + trace links—good for ideas and quotes.
2. Screenshot: Image—good when layout itself is the information.
3. Both can carry book location to return near the page from notes.
4. Screenshots do not replace every entry in the text highlight list; sidebar excerpts remain text-first.


## 5. Common Prompts
1. **Screenshot saved** includes the filename—confirm location in the Vault.
2. If copy image fails, save as file and insert instead.
3. If no active Markdown editor is found, open a note before capturing.
