The reader sidebar can gather the current book’s excerpts into cards, or show a date-based timeline across the whole bookshelf. Lists suit organizing one book; timelines suit reviewing what you clipped across books in recent days. Details below:

## 1. Open This Book’s Excerpt List
1. Open a book and show the sidebar.
2. Switch to the **Excerpts** tab.
3. The list loads indexed highlights and thoughts for this book.
4. With no excerpts yet, you are prompted: select text while reading and review it here later.


## 2. What Each List Card Can Do
Each excerpt card typically lets you:

1. View excerpt body and thought.
2. Click to locate the original text in the book.
3. **Jump to note**—open the Markdown (or other) file that holds the entry.
4. Delete a single excerpt (with confirmation as prompted).


## 3. Filter and Search
When excerpts pile up, use sidebar search.

1. Type keywords to match excerpt content.
2. You can also use property prefixes, e.g. `tag:`, `source:`, `comment:`, `type:`, `color:`, `chapter:`.
3. Narrow by thought status, note type, highlight color, and more.
4. With no matches, you are prompted to adjust conditions.


## 4. Sort
When excerpts show as **list cards**, you can change sort order.

1. Position in book: front to back, or back to front.
2. Created time: newest first, or oldest first.

> Note: Sort by position suits chapter-order review; sort by time suits **what I highlighted yesterday**.

## 5. List vs Timeline View
This book’s excerpt area can switch between two displays.

1. **List cards**: One card per entry—good for filtering and batch actions.
2. **Timeline view**: Review this book’s excerpts by date.


## 6. Batch Select, Export, and Delete
In list view you can enter batch selection.

1. Open **Batch select** from the menu and check multiple items.
2. **Select all current results** or **Clear selection**.
3. **Export selected excerpts** or **Export current filter results**. Export details in `Er-04a 导出笔记与模板`.
4. **Delete selected excerpts** confirms the count first.

> Note: Deleting excerpts may also affect re-highlight in the book. Confirm a copy remains in notes for important content.

## 7. Full-Bookshelf Timeline
Run **Full-bookshelf timeline** from the command palette, or open the matching view in the sidebar.

1. Browse excerpts from bookshelf books by date.
2. Good for reviewing a stretch of reading without opening each book.
3. Click an entry to try jumping back to the original text.
4. Without premium, you are told this is an advanced feature.
