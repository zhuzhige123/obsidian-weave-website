The reader can bind an Obsidian Canvas and write excerpts as nodes on the board, with re-highlight in the reader. Good for reading while laying out arguments as a map. Binding is connected or disconnected manually by you. Details below:

## 1. When to Use It
1. You want excerpts as card nodes instead of long Markdown inserts.
2. You need to extend nodes by direction and organize argument structure.
3. You still want to jump from nodes back to the book (precise positioning in `Er-02d 双向溯源与正文回显`).


## 2. Bind a Canvas
1. Open a book.
2. Under **Canvas map** in the reader menu, choose **New canvas** or connect to an existing canvas.
3. After creating, you see the path prompt; after connecting, the bound file is shown.
4. Use **Open canvas** to view the board immediately.
5. **Disconnect canvas** stops new excerpts from auto-writing to that board.


## 3. How Excerpts Become Nodes
1. Select body text and create an excerpt from the toolbar (color, thought, etc.—similar to Markdown excerpts).
2. The reader adds content to the current Canvas.
3. It may extend from a fixed anchor, from the selected node, or continue the previous node—follow on-screen prompts.
4. On success you are notified the excerpt was added to Canvas.


## 4. Direction
The menu can switch Canvas node extension direction—e.g. down, right, up, left.

1. Pick a main direction that fits your map so nodes do not pile up.
2. Current direction is shown in status.
3. Changing direction affects newly added nodes only; existing layout is usually not rearranged.


## 5. Re-Highlight and Jump
1. After writing to a node, matching sentences can re-highlight in the book.
2. Click book-related entries on Canvas nodes to try jumping back to the original text.
3. Disconnecting binding does not automatically delete nodes already on the canvas.
