The reader can export current-chapter body text, chapter excerpts, or whole-book highlights to Markdown—for archive, sharing, or continuing in another tool. Export templates control layout. Some **export with marks** and **whole-book excerpt bundle** features are premium support. Details below:

## 1. Export Current Chapter Body
1. Open the chapter to export.
2. From the menu, choose **Export current chapter as Markdown**.
3. You get an md file of chapter body text for editing outside the reader.


## 2. Export Current Chapter (With Excerpt Marks)
1. Choose **Export current chapter as Markdown (with excerpt marks)**.
2. Body text keeps excerpt-related marks so you can see what you highlighted.
3. This option is often premium support.


## 3. Export Excerpts Only
1. **Export current chapter excerpt notes as Markdown**: Highlights and thoughts for this chapter only.
2. **Export this book’s highlight excerpts as Markdown**: Highlights for the whole book.
3. In the sidebar excerpt list, you can also **Export selected excerpts** or **Export current filter results**. See `Er-02c 摘录汇总与时间线`.


## 4. Export Templates
**Export note template** in settings defines how export files look.

1. Open reader settings and manage export templates.
2. Edit, preview, and set default. Built-in presets include **Template 1**, **Template 2**, and more.
3. **Export template directory** sets which Vault folder holds template md files—the reader searches only there on export.
4. **This book’s note template** in the reader menu switches among templates.
5. Preview compares variables (book title, chapter, page, excerpt time, etc.). Save shortcut per UI (often Ctrl+S).


## 5. Common Template Fields
Export may include book info, author, publisher, reading progress, highlight color, thoughts, citation format, and more.

1. Citation style may be inline, block quote, academic, etc.—per chosen template.
2. When no page number exists, output may show **No page number**.
3. Time fields depend on excerpt timestamp toggle; see `Er-02b 高亮、想法与样式标注`.
