Weave is a set of Obsidian plugins around read → capture → schedule → review. There are exactly three plugins. They compose; this plugin does not require Weave Deck.

## Division of labor
| Plugin | Responsibility |
|--------|----------------|
| **Weave Incremental Reading** (this) | Reading points, topics, calendar scheduling, resume |
| **Weave Deck** | Memory decks, quizzes, excerpt-to-card, FSRS review |
| **Weave EPUB Reader** | In-vault EPUB reading, excerpts, chapter location |

## How to combine
1. Queue only — this plugin alone.
2. Also read/resume EPUB chapters — this plugin + Weave EPUB Reader.
3. Also create cards and review — this plugin + Weave Deck.
4. Full loop (read → capture → schedule → review) — all three.

## Outside the family (summary)
PDF++, RSS clip folders via subscription, official Canvas / web viewer / selection hotkeys, Video Extended timestamp links, Excalidraw drawing links, and how they form one daily loop—see `Ir-00b 整体学习流程与协同`.
