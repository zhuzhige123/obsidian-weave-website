Practical habits to keep the main path stable—not a feature dump.

## One primary path
1. Add one item — calendar **Add link**.
2. Split a book / long note — **Import reading materials**.
3. Clip inbox — **Folder subscription** (premium).
4. Start the day — open the **incremental reading calendar**.

Do not default to the experimental paragraph workbench or any removed legacy main reading view.

## Stable topic names
One plan → one `.irdeck` name. Avoid parallel spellings that fragment filters.

## Capture with locators
Markdown block IDs, PDF++ selections, Canvas node IDs, EPUB location links. File-only points enqueue, but resume feels weaker.

## Respect load
Watch the heatmap and day-load summary. Don’t pin every new item to today. Clear overdue with reschedule, restore-from-suspend, or rebalance. Know Add to today vs Schedule normally for subscriptions.

## Free loop first
Ship add → open today → resume → mark progress before unlocking PDF/EPUB import, subscription, timers, analytics, associated notes, or deep strategy knobs.

## Don’t lean on unfinished surfaces
Tag groups are still being improved; the paragraph workbench is experimental; FSRS belongs to Weave Deck—not this scheduler.

## Back up the data root
Include `weave Incremental reading/` (or your custom root) and every `.irdeck`. Confirm the old folder before changing the path.
