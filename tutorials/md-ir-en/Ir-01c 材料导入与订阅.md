Use **Import reading materials** when a whole Markdown file, PDF outline, or EPUB outline should become many reading points. Use **folder subscription** (premium) when a clip/inbox folder should keep topping up a topic. Both differ from daily Add link.

## When to import
Entry: calendar **More → Import reading materials**.

Fits: split long notes by headings, pick chapters from an outline, preview then confirm. Poor fit: one casual web clip or selection per day (use Add link).

## Import steps
1. Choose files (one batch = one type only: `md` / `pdf` / `epub`).
2. PDF / EPUB open an outline step so you can pick chapters.
3. Choose a split mode and options.
4. Preview generated points, then confirm.

## Formats and limits
**Markdown (free):** split by headings, blank lines, and similar rules; whole-file mode can reference or copy. Compatibility import folder defaults to plugin data folder / IR (legacy path—you need not manage it by hand).

**PDF / EPUB (premium):** bookmark-style points from outlines with resume info. EPUB outline parsing depends on Weave EPUB Reader. Precise PDF selections work best with PDF++.

## Folder subscription (premium)
Configure: Settings → Weave Incremental Reading → Basic → Subscribe clipping folders (rules, folders, bound topics, initial schedule mode, …).

Manual sync: calendar **More → Update subscribed folders**, or the matching command. Background sync also runs on startup and relevant vault changes.

**Initial schedule mode (important):**
1. **Add to today** — pin new materials on today (not smoothed across the horizon).
2. **Schedule normally** — place due dates by horizon / load rules.

Subscription targets **Markdown**. Without activation the entry may be hidden or locked.
