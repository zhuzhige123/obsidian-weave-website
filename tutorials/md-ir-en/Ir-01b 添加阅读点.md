To add **one** reading point, use Add link / Add reading target—not material import. Add fits one URL, wikilink/block, selection, or Canvas node. Import fits turning a whole document or book into many points.

## Recommended entry
1. Calendar **“+” / Add link** (daily primary path).
2. Command palette **Add reading target to incremental reading** (same modal).

## Five steps in the modal
1. Paste a link, or use Current location for a Markdown block / line anchor.
2. Confirm the reading-point name.
3. Choose a topic (`.irdeck`; create if needed).
4. Pick the first reading day (manual or recommended).
5. Optionally create a reading note or append a source marker → confirm to enqueue.

## Pasteable types
1. Web: `https://…`
2. Vault links / block refs: `[[Note]]`, `[[Note#^blockId]]`
3. PDF++ selection or bookmark links (including links in PDF callouts)
4. Canvas nodes: `[[board.canvas#^nodeId]]`
5. EPUB location links (requires Weave EPUB Reader)

## Other shortcuts
1. Markdown selection: command Create incremental reading point from selection.
2. Obsidian browser: viewer / selection → Add to incremental reading.
3. Canvas node: node menu → Add to incremental reading.

## Tips
1. Prefer stable locators (block IDs, PDF++ selections, node IDs) over file-only links.
2. One point = one pending task; after splitting a long source, use continuous reading on the calendar.
3. Be honest about the first day—pinning everything to today spikes load.
