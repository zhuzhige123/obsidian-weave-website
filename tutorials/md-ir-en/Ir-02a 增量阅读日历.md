The incremental reading calendar is the plugin’s main surface: browse pending, scheduled, and overdue reading points by date, and read load from the month heatmap.

## Layout
1. **Top:** month heatmap — which days are heavy or empty.
2. **Bottom:** reading materials for the selected day.
3. **Toolbar:** add, search, continue-reading suggestions, tutorial, more.

Open via the ribbon calendar icon or command Open incremental reading calendar. You can also open a `.irdeck` and switch between topic view and calendar.

## Daily loop
1. Open the calendar on today (or the day you mean to work).
2. Prefer overdue and high-priority items.
3. Open a point and resume in the source.
4. Mark progress (or suspend / reschedule / archive).
5. Capture with “+” / Add link; bulk-split with More → Import reading materials.

## Toolbar
| Control | Role |
|---------|------|
| **+ / Add link** | Create one reading point |
| Search | Find materials |
| Continue-reading suggestions | Extra suggestions; suspended items can restore to today |
| Help / tutorial | In-plugin short tutorial |
| More | Import, update subscriptions, data management, view modes, … |

Click the **topic chip** next to the month title to filter All vs one topic.

## Continuous reading
When one source was split into many points, advance by source instead of hunting the list.

1. Context menu → More actions → **Continuous reading**.
2. An expand control shows siblings from the same source.

Part of basic scheduling assistance—no premium license required.

## Suspend
Menus often say **Suspend**; the suggestions panel may say **Suspended**—same “parked for later” idea. Restore to today when ready.

## Free vs premium (calendar-related)
Calendar + Markdown main flow is free. Common premium surfaces: reading timer, background wall, analytics, PDF/EPUB import, folder subscription, associated notes, deep strategy customization.
