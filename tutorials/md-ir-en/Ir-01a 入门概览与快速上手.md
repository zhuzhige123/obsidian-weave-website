Weave Incremental Reading is a standalone incremental-reading controller: turn Markdown, block refs, PDF, Canvas, web, and EPUB into schedulable, resumable reading points, driven by topics and a calendar. It does not require Weave Deck.

## Three core concepts
| Concept | Meaning |
|---------|---------|
| **Reading point** | One reading task with source tracing; jump back to the original location from the queue. |
| **Topic (`.irdeck`)** | A container for reading points, stored as a topic file in your vault. |
| **Incremental reading calendar** | Main view: browse pending, scheduled, and overdue items by date. |

## Five-minute start
1. Install and enable the plugin (Obsidian ≥ 1.8.7).
2. Open the **incremental reading calendar** (ribbon calendar icon, or command Open incremental reading calendar).
3. Click **“+” / Add link**: paste source → name → topic → first day → save.
4. Open today’s item, resume at the source, mark progress; scheduling picks the next appearance.

Prefer **Add link** for daily capture; use Import reading materials for whole documents or books.

## Free vs premium (summary)
**Free:** calendar and Markdown points, topic management, basic scheduling and resume, Add link, Markdown split import, continuous reading, Markdown focused reading, data management.

**Premium:** PDF/EPUB chapter import, folder subscription, deep scheduling customization and interleaving, analytics, reading timer, calendar background wall, associated notes, and more. Tag groups are still being improved—do not rely on them yet.

If Weave Deck is activated, this plugin can inherit that license. Standalone activation: Settings → Weave Incremental Reading → License.

## Data and privacy (summary)
Points, topics, and schedules stay in the local vault by default. The plugin does not actively upload note bodies. Uninstall does not auto-delete `.irdeck` data.
