日常新增**一条**阅读点，请用「添加链接 / 添加阅读目标」，而不是材料导入。添加适合一条 URL、一个双链或块、一个选区、一个 Canvas 节点；导入适合把整份文档或整书拆成大量阅读点。

## 推荐入口
1. 日历顶部 **「+」/ 添加链接**（日常主路径）。
2. 命令面板 **添加阅读目标到增量阅读**（同一模态窗流程）。

## 模态窗五步
1. 粘贴链接，或点击「当前位置」捕获 Markdown 编辑器中的块 / 行锚点。
2. 确认阅读点名称。
3. 选择归属专题（`.irdeck`；可新建）。
4. 安排首次阅读日（自选或系统推荐）。
5. 可选：创建阅读笔记、在源笔记追加标记 → 确认后写入队列并排期。

## 支持粘贴的类型
1. 网页：`https://…`
2. Vault 链接 / 块引用：`[[笔记]]`、`[[笔记#^块ID]]`
3. PDF++ 选区或书签链接（callout 内亦可）
4. Canvas 节点：`[[画布.canvas#^nodeId]]`
5. EPUB 定位链接（需安装并启用 Weave EPUB Reader）

## 其它快捷入口
1. Markdown 选区：命令「从当前选区创建增量阅读点」。
2. Obsidian 浏览器：网页菜单 / 选区右键 → 添加到增量阅读。
3. Canvas 节点：节点菜单 → 添加到增量阅读。

## 建议
1. 能粘贴稳定定位就粘贴（块 ID、PDF++ 选区、节点 ID），少用只有文件名、没有位置的模糊链接。
2. 一条阅读点只表达一件待读任务；长文拆分后可用日历里的连续阅读。
3. 首次阅读日如实选择；全部丢到今天会迅速抬高当日负载。
