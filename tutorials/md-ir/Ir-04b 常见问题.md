按症状查找。若仍无法解决，请到 GitHub Issues 反馈，并注明 Obsidian 版本、插件版本与平台。

## 找不到增量阅读日历
命令面板搜索「打开增量阅读日历」；确认插件已启用。旧版「主阅读界面」入口若仍存在，应已重定向到日历——请改用日历作为唯一主界面。

## 新建专题后搜索里暂时没有
稍候或重开日历侧栏；确认 `.irdeck` 写在当前数据根下的 `points/`；用数据管理工具检查专题是否可读。

## 粘贴后无法识别 / 导入入口不可用
检查链接是否完整；同批导入是否混了 md/pdf/epub（不允许）。PDF/EPUB 导入需高级功能；EPUB 目录依赖 Weave EPUB Reader。

## 订阅不收录或排期不符合预期
确认订阅的是 Markdown 文件夹、规则已绑定专题并启用；手动执行「更新订阅文件夹」。分清「添加到今天」与「按算法正常调度」——只有后者会按视野均摊 due。

## 提示来源丢失 / 打不开原文
检查源文件是否移动、重命名或删除；PDF++ / EPUB / Canvas 节点 / 块 ID 是否仍有效。EPUB 回跳需安装并启用 Weave EPUB Reader；高亮不会自动变成阅读点。

## PDF 只能打开文件、到不了选区
请用 PDF++ 生成的选区 / 书签链接再添加；仅有文件路径的阅读点无法提供精确选区。

## 完成后很久不再出现或出现过勤
查看策略（处理流 vs 阅读列表）与间隔相关选项；是否被暂停或归档；日上限与时间预算是否卡住放出。本插件调度不是 FSRS——间隔复习请用 Weave Deck。

## 标签组不生效
标签组仍在完善中，可能无法正常使用。请改用专题、优先级与基础调度。

## 高级功能带锁 / 主插件已激活仍提示未授权
在设置 → 授权激活，或确认 Weave Deck 授权可继承后重载插件。可开启「高级功能预览」查看入口，但未激活仍不可用。

## 换机后专题消失
是否同步了数据根文件夹（默认 `weave Incremental reading/`）；设置中的数据路径是否与实际文件夹一致。
