增量阅读日历是本插件的主界面：按日期查看待处理、已排期与逾期的阅读点，并用月历热力感知负载。

## 界面结构
1. **上方**：月历热力——哪几天挤、哪几天空。
2. **下方**：选中日期的阅读材料列表——当天真正要处理的队列。
3. **顶部工具栏**：添加、搜索、继续阅读建议、教程、更多。

打开方式：功能区日历图标，或命令「打开增量阅读日历」。也可打开某个 `.irdeck`，在专题视图与日历之间切换。

## 日常循环
1. 打开日历，确认今天（或要处理的日期）。
2. 查看当日列表：优先逾期与高优先级。
3. 打开阅读点，在原文续读。
4. 完成后标记进度（或暂停 / 改期 / 归档）。
5. 需要新材料时用顶部「+」/ 添加链接；整书拆分用「更多 → 导入阅读材料」。

## 顶部工具栏
| 控件 | 作用 |
|------|------|
| **+ / 添加链接** | 单条创建阅读点（日常主入口） |
| 搜索 | 在材料中查找 |
| 继续阅读建议 | 额外建议；含已搁置，可恢复到今天 |
| 帮助 / 教程 | 插件内短教程 |
| 更多 | 导入、更新订阅、数据管理、视图模式等 |

月历标题旁的**专题 chip** 可点击：在「全部」与某一专题之间切换。

## 连续阅读
适合同一文档被拆成多个阅读点时，按来源连续推进。

1. 阅读点右键 / 长按 → 更多操作 → **连续阅读**。
2. 开启后，项旁出现展开按钮，可展开同一来源下的其它阅读点。

该能力属于基础调度辅助，无需高级授权。

## 暂停与搁置
菜单文案常见为**暂停**；继续阅读建议中常见为**已搁置**——指同一类「先放下、稍后再拉回」的状态。可将搁置项恢复到今天。

## 免费与高级（日历相关）
日历与 Markdown 主流程免费。常见需激活的能力：阅读计时器、日历背景墙、统计分析、PDF/EPUB 导入、订阅文件夹、关联笔记、调度策略深度自定义等。
