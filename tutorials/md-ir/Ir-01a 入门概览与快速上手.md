Weave Incremental Reading 是独立的增量阅读主控：把 Markdown、块引用、PDF、Canvas、网页、EPUB 等收成可排期、可续读的阅读点，用专题与日历推进节奏。不依赖 Weave Deck 即可单独使用。

## 三个核心概念
| 概念 | 说明 |
|------|------|
| **阅读点** | 一条待阅读任务，带来源溯源；可从队列一键回跳原文。 |
| **专题（.irdeck）** | 阅读点的容器，以专题文件保存在知识库中。 |
| **增量阅读日历** | 主界面：按日期查看待处理、已排期与逾期项，安排每日节奏。 |

## 五分钟上手
1. 安装并启用插件（Obsidian ≥ 1.8.7）。
2. 打开**增量阅读日历**（功能区日历图标，或命令「打开增量阅读日历」）。
3. 点顶部 **「+」/ 添加链接**：粘贴来源 → 命名 → 选专题 → 安排首次阅读日 → 保存。
4. 在今日列表打开条目，回跳原文续读；完成后标记进度，系统安排下次出现。

日常新增请优先走**添加链接**；整份文档或整书拆分再用「导入阅读材料」。

## 免费与高级（摘要）
**免费：** 日历与 Markdown 阅读点、专题管理、基础调度与续读、添加链接、Markdown 拆分导入、连续阅读、Markdown 聚焦阅读、数据管理。

**高级（需激活）：** PDF/EPUB 章节导入、订阅文件夹、调度策略深度自定义与交错学习、统计分析、阅读计时器、日历背景墙、关联笔记等。标签组仍在完善中，勿作主流程依赖。

若已激活 Weave Deck，本插件可继承授权。独立激活：设置 → Weave Incremental Reading → 授权。

## 数据与隐私（摘要）
阅读点、专题与调度默认保存在本地知识库；插件不主动上传笔记正文。卸载不会自动删除已创建的 `.irdeck` 数据。
