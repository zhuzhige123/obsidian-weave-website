阅读器负责把书读完、把摘录留下。制卡复习、增量阅读日程、AI 拆分则由 Weave 系列其它插件承接。这些联动不占用阅读器自己的高级许可，但需要安装对应插件；AI 还需自行配置密钥。以下是详细介绍：

## 1. 摘录制卡
1. 在书中选中一段。
2. 工具条选择「制卡」，内容会填进 Weave 的记忆卡片创建流程。
3. 保存后，卡片可带上阅读器溯源，便于从学习界面跳回原书。
4. 未安装 Weave 时，该入口不可用或会提示缺少能力。


## 2. 增量阅读
若已安装独立的增量阅读插件：

1. 在目录章节菜单中选择「添加到增量阅读」。
2. 成功后，该章会进入增量阅读任务，而不是只在阅读器里留个书签。
3. 未安装或服务未就绪时，会提示功能暂不可用，且不会写入任务。


## 3. AI 面板与选区搜索
1. 阅读器提供选中文本搜索、AI 面板等入口（帮助 / 工具菜单，以界面为准）。
2. 自定义 AI 拆分依赖 Weave 侧已配置的拆分功能。
3. 没有可用拆分功能时会提示暂无配置。
4. AI 会把选区发到你配置的第三方模型，注意不要把不宜外传的文本送出去。

>备注：阅读器内 AI 不是「必须开通阅读器高级」才能点；但没有 Weave 与 API Key，面板帮不上忙。

## 4. 生词本
从选区加入生词本、正文标注词库，见 `Er-03b 生词标注与词汇表`。复习仍在 Weave 记忆学习中完成。

## 5. 授权怎么算
1. 阅读器高级：时间线、双向精确定位、段落模式、书单等，用阅读器激活码，或继承已激活的 Weave。
2. 制卡 / 增量阅读 / AI：不单独扣阅读器高级名额，但各插件自己的要求仍在。
3. 只装阅读器、不装 Weave，上述联动入口会缺少宿主。


## 6. 推荐组合
1. **只读书做笔记**：阅读器 + Markdown / Canvas，不必装 Weave。
2. **读书并间隔复习**：阅读器 + Weave，划词制卡或收生词。
3. **长书拆章慢慢读**：阅读器 + 增量阅读插件，目录送章。
4. **三者都要**：都装，阅读器当入口，另外两个当加工厂。
