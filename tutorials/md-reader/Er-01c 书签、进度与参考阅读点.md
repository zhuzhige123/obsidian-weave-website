阅读器会记住你读到哪里，也支持手动钉住两个不同位置：当前页书签，以及参考阅读点。进度适合「接着上次读」；书签适合章节内多处标记；参考阅读点适合临时离开、对照前后文后再跳回来。以下是详细介绍：

## 1. 阅读进度会保存在哪里
每本书的进度、书签与封面等信息，会写入 Vault 里的书籍数据笔记（默认在 `Weave EPUB Reader` 目录，文件名形如 `data_*.md`）。

1. 关闭阅读器、切换书籍时，一般会保存最后阅读位置。
2. 书架上会显示阅读进度百分比，以及「继续阅读」等提示。
3. 这些数据在库内，可随 Vault 一起同步到其它设备。


## 2. 自动记录阅读位置
可在设置中开启「自动记录阅读位置」。

1. 连续阅读达到设定页数后，自动保存当前位置。
2. 页数范围有上下限，默认值以设置页说明为准。
3. 即使关闭自动记录，关闭阅读器或换书时仍会保存最后位置。


## 3. 当前页书签
书签钉的是「这一页 / 这一处」，可在一本书里保存多条。

1. 读到想记住的位置，点击顶部「添加当前页书签」，或使用菜单中的对应项。
2. 成功后会提示书签已添加；若当前页已有书签，会提示已存在。
3. 打开侧栏书签列表，可跳转到某条书签，或删除它。
4. 空列表时会提示：点顶部书签按钮即可保存当前位置。


## 4. 参考阅读点
参考阅读点同一时间通常只保留一处「对照锚点」，适合前后翻找资料后再跳回。

1. 在需要回头的位置，使用「记录参考阅读位置」或工具栏上的记录功能键。
2. 记录后，可用「跳转到参考阅读位置」立刻回去。
3. 位置变了，可用「更新阅读位置」覆盖为当前处。
4. 不再需要时，「清除参考阅读位置」。
5. 顶部可能显示徽章或贴纸，提示已记录的参考点及相对进度。


## 5. 进度、书签、参考点怎么选
可按目的分开用，不必互相替代。

1. **接着读**：依赖自动或关闭时保存的最后阅读点，从书架点「继续阅读」。
2. **本章有好几处要反复看**：用当前页书签，在侧栏列表里跳。
3. **暂时去前面核对一句，还要回到现在这句**：用参考阅读点。
4. **整本书读完了**：可用「标记为已读完」；续读位置仍按上面规则，不会因为标记而自动清掉书签。


## 6. PDF 的特殊情况
PDF 在书架中，但正文由 Obsidian 自带查看器打开。

1. 先打开该 PDF。
2. 在书架书籍菜单中选择「记住当前位置」，或使用命令「记住 PDF 阅读位置」（以命令面板中的实际名称为准）。
3. 成功后可能提示页码与进度百分比。
4. 未打开 PDF 就去记住位置，会提示请先打开该文件。


## 7. 常见提示
1. 「尚未记录参考阅读位置」：先记录，再跳转。
2. 「当前页已有书签」：同一页不必重复添加。
3. 「书签不存在或已删除」：列表已刷新，直接再添加即可。
4. 源文件丢失时，书架可能移除该书；摘录笔记仍留在原来的 Markdown 等文件中。
