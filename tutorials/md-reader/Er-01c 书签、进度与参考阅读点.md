阅读器会记住你读到哪里，也支持手动钉住两类位置：当前页书签，以及**段落级接着读位置**。进度适合「接着上次读」；书签适合章节内多处标记；接着读适合选中一段正文钉住精确段落，再次打开时定位并短暂高亮，或临时离开对照前后文后再跳回来。以下是详细介绍：

## 1. 阅读进度会保存在哪里
每本书的进度、书签、计时与书架归属等，集中写在书籍数据目录下的 `library-state.json`（默认文件夹常见为 `Weave Reader`）；封面缓存在对应 `covers/` 中。

1. 关闭阅读器、切换书籍时，一般会保存最后阅读位置。
2. 书架上会显示阅读进度百分比，以及「继续阅读」等提示。
3. 这些数据在库内，可随 Vault 一起同步到其它设备。

>备注：旧版曾为每本书生成 `data_*.md`。若库中仍有残留，插件可能提示迁入 `library-state.json` 并可清理旧页；你的摘录仍在原来的 Markdown / Canvas 等文件中，不受影响。

## 2. 自动记录阅读位置
可在设置中开启「自动记录阅读位置」。它服务的是**连续向前阅读**，不是把每次溯源跳转都当成续读。

1. 连续阅读达到设定页数后，自动保存当前位置。
2. 页数范围有上下限，默认值以设置页说明为准。
3. 即使关闭自动记录，关闭阅读器或换书时仍会保存最后位置。
4. 若更在意「不要被查阅原文误更新」，请以段落级接着读钉点为主，见下一节与 `Er-00a 设计理念下的一些考虑`。

## 3. 当前页书签
书签钉的是「这一页 / 这一处」，可在一本书里保存多条。

1. 读到想记住的位置，点击顶部「添加当前页书签」，或使用菜单中的对应项。
2. 成功后会提示书签已添加；若当前页已有书签，会提示已存在。
3. 打开侧栏书签列表，可跳转到某条书签，或删除它。
4. 空列表时会提示：点顶部书签按钮即可保存当前位置。

## 4. 段落级接着读位置
接着读同一时间通常只保留一处续读锚点，并且支持**选中文本后的段落级精确定位**（基础能力）。

1. 在正文中选中要续读的那一句或一段，在选区工具条点「钉为接着读」，或使用菜单 / 工具栏中的对应项。
2. 也可以不选文本、从工具栏记录当前位置；需要最准时，优先用选区钉段落。
3. 记录后，可用「跳转到接着读位置」立刻回去；再次打开本书时也会尽量定位到该段落并短暂高亮。
4. 连续翻页、溯源查阅**不会**自动改写这个钉点；要更新时请重新选中文本再钉一次。
5. 不再需要时，「清除接着读位置」。
6. 顶部可能显示徽章或贴纸；底部进度刻度条上也可见接着读图钉（若已开启刻度条）。见 `Er-03i 阅读进度刻度条`。

>备注：段落级钉点解决的是「回到这一句」，与「关闭阅读器时保存的最后浏览位置」不同。后者仍可能随关闭 / 换书更新；前者专门保护你亲手钉住的续读句。

## 5. 进度、书签、接着读怎么选
可按目的分开用，不必互相替代。

1. **接着读到精确段落**：选中文本钉段落级接着读；从书架点「继续阅读」时也会尽量落到该钉点。
2. **本章有好几处要反复看**：用当前页书签，在侧栏列表里跳。
3. **暂时去前面核对一句，还要回到现在这句**：用接着读位置（先钉再翻）。
4. **只想线性往下读、少操心钉点**：可靠关闭时保存或连续阅读自动保存；仍建议重要断点用段落级接着读加固。
5. **整本书读完了**：可用「标记为已读完」；续读位置仍按上面规则，不会因为标记而自动清掉书签。

## 6. PDF 的特殊情况
PDF 在书架中，但正文由 Obsidian 自带查看器打开。

1. 先打开该 PDF。
2. 在书架书籍菜单中选择「记住当前位置」，或使用命令「记住 PDF 阅读位置」（以命令面板中的实际名称为准）。
3. 成功后可能提示页码与进度百分比。
4. 未打开 PDF 就去记住位置，会提示请先打开该文件。

## 7. 常见提示
1. 「尚未钉接着读位置」：先选中文本钉住，再跳转。
2. 「当前页已有书签」：同一页不必重复添加。
3. 「书签不存在或已删除」：列表已刷新，直接再添加即可。
4. 源文件丢失时，书架可能移除该书；摘录笔记仍留在原来的 Markdown 等文件中。
