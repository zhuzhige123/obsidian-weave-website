阅读器可以绑定一张 Obsidian Canvas，把摘录写成白板上的节点，并在阅读器里回显。适合一边读书、一边把论点铺成图。绑定状态由你手动连接或断开。以下是详细介绍：

## 1. 适用场景
1. 希望摘录以卡片节点出现，而不是插入长篇 Markdown。
2. 需要按方向延伸节点，整理论证结构。
3. 仍希望从节点跳回原书（精确定位见 `Er-02d 双向溯源与正文回显`）。


## 2. 绑定一张画布
1. 打开一本书。
2. 在阅读器菜单「Canvas 导图」中，选择「新建 canvas」或连接到已有画布。
3. 新建成功后会提示路径；连接已有画布后会显示当前绑定文件。
4. 可用「打开 canvas」立刻查看白板。
5. 「断开 canvas」后，新摘录不再自动写入该图。


## 3. 摘录如何进节点
1. 选中正文，用工具条创建摘录（颜色、想法等与 Markdown 摘录类似）。
2. 阅读器把内容加到当前 Canvas。
3. 可能从固定锚点延伸、从选中节点延伸，或续写上一节点，具体以当时提示为准。
4. 成功后会提示已添加到 Canvas。


## 4. 方向
菜单可切换 Canvas 节点延伸方向，例如向下、向右、向上、向左。

1. 按你的图结构选择一个主方向，避免节点叠成一团。
2. 当前方向会在状态里提示。
3. 改方向只影响之后新增的节点，一般不会重排已有图。


## 5. 回显与跳转
1. 写入节点后，书中对应句子可回显高亮。
2. 在 Canvas 中点击节点上的书籍相关入口，可尝试跳回原文。
3. 断开绑定不会自动删除已经写进画布的节点。
