阅读摘录只有写进 Vault 里的文件，才会成为可同步、可回链的笔记。阅读器通过这些文件里的溯源链接，在书中回显高亮。以下是详细介绍：

## 1. 摘录可以落到哪里
可按场景选用：

1. **按书自动生成的摘录 Markdown**（默认）：高亮时按书名创建或追加，见下一节。
2. **你指定的 Markdown 笔记**：打开一篇 `.md`，把光标放在要插入的位置，再开顶部「自动化」。
3. **Canvas 白板**：绑定一张画布后，摘录会写成节点。见 `Er-02e Canvas 脑图摘录`。
4. **Weave Review 牌组**：安装 Weave Review 后，可把内容填进记忆卡片。见 `Er-04c 与 Weave Review 制卡、增量阅读、AI 联动`。

>备注：阅读器不会把摘录只存在「看不见的插件缓存」里当正式笔记。要长期保留，必须落到库文件中。

## 2. 高亮自动写入书籍摘录笔记
设置「高亮自动写入书籍摘录笔记」默认开启，与顶部「自动化」是两套开关。

1. **自动化关闭**时：选中文本并高亮，会在 Obsidian **新笔记默认文件夹**按书名创建一份摘录 md（若该书已有对应笔记则追加）。
2. 笔记带书籍溯源与 frontmatter 标识，可供正文回显与侧栏摘录列表索引。
3. 不需要自动建笔记时，到阅读器设置中关闭该项；关闭后不影响「自动化」插入与 Canvas。
4. 设计取舍见 `Er-00a 设计理念下的一些考虑`。

>备注：这是「先划线就能留下来」的默认路径；若你更想写进某一篇正在编辑的笔记，请用下一节的自动化插入。

## 3. 自动化：写入当前笔记或 Canvas
顶部「自动化」决定高亮是否写入**当前工作流**。

1. **开（插入）**：摘录直接写入当前 Markdown 光标处，或已绑定的 Canvas。适合边读边记进指定文件。
2. **关**：不再插入当前打开的笔记；若上一节的「高亮自动写入书籍摘录笔记」仍开启，高亮仍会写入按书生成的摘录 md。
3. 选区工具条上的「复制」仍可把内容放进剪贴板，便于贴到其它软件。

## 4. 推荐操作顺序（写进指定笔记）
第一次想边读边写进某一篇笔记时，按下面顺序最稳。

1. 新建或打开一篇 Markdown 笔记，作为本书的阅读笔记。
2. 把光标放在希望插入摘录的位置。
3. 打开图书，开启顶部「自动化」。
4. 在正文中选中一段文字，用选区工具条创建高亮或摘录。
5. 切回笔记，确认内容已插入，并带有可点击的书籍溯源。
6. 点击笔记里的书籍图标或链接，应能跳回书中对应位置。

>备注：未找到活动的 Markdown 编辑器时，自动化插入会失败。插入前请确保笔记标签页仍在，且光标在编辑区。若只想用按书自动生成的摘录笔记，可不开启自动化。

## 5. 选区工具条
选中正文后会出现工具条，常见操作包括：

1. 选择高亮颜色。
2. 插入摘录（自动化开启时写入当前笔记）或复制。
3. 添加想法。
4. 复制纯文本。
5. 制卡（需 Weave Review）。
6. 加入生词本（需相关能力，见 `Er-03b 生词标注与词汇表`）。

## 6. 为什么高亮一会儿就没了
常见原因都与「没有落到库文件」有关。

1. 「高亮自动写入书籍摘录笔记」已关闭，又没有开自动化、也没有绑定 Canvas，高亮无处可写。
2. 自动化开启，但没有打开可用的 Markdown / Canvas，插入失败。
3. 插入的内容里缺少溯源链接，阅读器无法据此在正文回显。
4. 源笔记被删、被移出库，或路径失效。

>备注：侧栏「摘录」列表汇总的是能索引到的库内摘录。列表是空的，通常说明还没有成功写入笔记。

## 7. 正文回显是怎么回事
写入笔记后，阅读器会扫描这些摘录里的书籍定位信息，在原书对应句子上画出高亮。

1. 同一段摘录改颜色、加想法后，回显会尽量跟着更新。
2. 在笔记或 Canvas 中点击书籍图标，可跳回原书（精确定位可能需高级支持，见 `Er-02d 双向溯源与正文回显`）。
3. 删除笔记里的那条摘录，书中回显也会随之消失。

>备注：回显依赖笔记内容，不是另存一份互不相干的高亮库。改笔记就是在改这本书的标注。

## 8. 移动端与多设备
摘录在 Vault 文件中，可随你使用的同步方式在设备间一致。

1. 同步整个库（官方 Sync、iCloud、网盘同步 Vault 等）。
2. 不必强行同步 `.obsidian/plugins/weave-epub-reader/` 下的缓存。
3. 换设备后先打开笔记确认摘录还在，再打开书查看回显。
