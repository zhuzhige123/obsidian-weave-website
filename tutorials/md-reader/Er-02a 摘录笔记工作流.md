阅读摘录只有写进 Vault 里的文件，才会成为可同步、可回链的笔记。阅读器通过这些文件里的溯源链接，在书中回显高亮。若不满足保存条件，选中后往往只有短暂高亮，关掉或刷新后就没有实质数据。以下是详细介绍：

## 1. 摘录保存在哪里
可把摘录落到三类位置，三者可按场景选用。

1. **Markdown 笔记**：最常用。打开一篇 `.md`，把光标放在要插入的位置。
2. **Canvas 白板**：绑定一张画布后，摘录会写成节点。见 `Er-02e Canvas 脑图摘录`。
3. **Weave Deck 牌组**：安装 Weave Deck 后，可把内容填进记忆卡片。见 `Er-04c 与 Weave Deck 制卡、增量阅读、AI 联动`。

>备注：阅读器不会把摘录只存在「看不见的插件缓存」里当正式笔记。要长期保留，必须落到库文件中。

## 2. 推荐操作顺序
第一次做摘录，按下面顺序最稳。

1. 新建或打开一篇 Markdown 笔记，作为本书的阅读笔记。
2. 把光标放在希望插入摘录的位置。
3. 打开图书，开启顶部「自动化」（自动模式开：插入）。
4. 在正文中选中一段文字，用选区工具条创建高亮或摘录。
5. 切回笔记，确认内容已插入，并带有可点击的书籍溯源。
6. 点击笔记里的书籍图标或链接，应能跳回书中对应位置。

>备注：未找到活动的 Markdown 编辑器时，自动插入会失败。插入前请确保笔记标签页仍在，且光标在编辑区。

## 3. 自动插入与复制
顶部「自动化」在两种输出方式之间切换。

1. **开（插入）**：摘录直接写入当前笔记光标处。适合边读边记。
2. **关（复制）**：摘录进入剪贴板，由你自行粘贴。适合暂时不想动当前笔记，或要贴到别的软件。


## 4. 选区工具条
选中正文后会出现工具条，常见操作包括：

1. 选择高亮颜色。
2. 插入摘录（或复制，取决于自动模式）。
3. 添加想法。
4. 复制纯文本。
5. 制卡（需 Weave Deck）。
6. 加入生词本（需相关能力，见 `Er-03b 生词标注与词汇表`）。


## 5. 为什么高亮一会儿就没了
常见原因都与「没有落到库文件」有关。

1. 没有打开 Markdown，也没有绑定 Canvas，自动插入无处可写。
2. 自动模式关闭，只复制了剪贴板，又没有粘贴到笔记。
3. 插入的内容里缺少溯源链接，阅读器无法据此在正文回显。
4. 源笔记被删、被移出库，或路径失效。

>备注：侧栏「摘录」列表汇总的是能索引到的库内摘录。列表是空的，通常说明还没有成功写入笔记。

## 6. 正文回显是怎么回事
写入笔记后，阅读器会扫描这些摘录里的书籍定位信息，在原书对应句子上画出高亮。

1. 同一段摘录改颜色、加想法后，回显会尽量跟着更新。
2. 在笔记或 Canvas 中点击书籍图标，可跳回原书（精确定位可能需高级支持，见 `Er-02d 双向溯源与正文回显`）。
3. 删除笔记里的那条摘录，书中回显也会随之消失。

>备注：回显依赖笔记内容，不是另存一份互不相干的高亮库。改笔记就是在改这本书的标注。

## 7. 移动端与多设备
摘录在 Vault 文件中，可随你使用的同步方式在设备间一致。

1. 同步整个库（官方 Sync、iCloud、网盘同步 Vault 等）。
2. 不必强行同步 `.obsidian/plugins/weave-epub-reader/` 下的缓存。
3. 换设备后先打开笔记确认摘录还在，再打开书查看回显。
