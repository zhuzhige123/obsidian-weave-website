生词标注把 Weave 词库里的词，在 EPUB 正文和 Markdown 预览中标出来，并允许从选区加入生词本。适合外文阅读时顺手收词、之后在 Weave 里复习。需要阅读器高级支持，且加入生词本需要安装 Weave。以下是详细介绍：

## 1. 总开关
在阅读器设置「词汇」或基础设置中：

1. 「启用生词标注」：总闸。关闭后，正文标注菜单和选区「加入词库」等入口会隐藏，适合完全不需要词汇学习的人。
2. 默认开启。不需要时关掉，界面更干净。


## 2. 正文生词标注
1. 打开「正文生词标注」或菜单「开启标注」。
2. EPUB 正文，以及 Markdown 的阅读 / 实时预览中，词库里的词会加下划线一类标记。
3. 默认可保持关闭，以免泛读时满屏标记。精读某章再打开。
4. 可分别勾选显示「新词」「学习中」「已掌握」「到期待复习」。
5. 「已掌握」默认可能关闭；若明明词库里有词却看不见，先打开此项试试。


## 3. 与摘录高亮共显
「与摘录笔记共显」决定生词线与摘录色块是否同时出现。

1. 开启：生词标注和高亮一起显示。
2. 关闭：打开生词标注时，正文暂时隐藏摘录高亮，侧栏摘录列表不受影响。


## 4. 从书中加入生词
1. 选中单词或短语。
2. 在工具条选择加入 Weave 生词本（文案可能为「生词」）。
3. 默认牌组名常为「生词本」，以实际选择为准。
4. 已在词库中的词会提示已存在。
5. 未安装 Weave 时会提示无法使用生词本。

>备注：社区插件 fingertip translation 等取词浮窗，也可提供「添加到 Weave」一类入口，与阅读器收词是互补关系。见 `We-01a 新建卡片`。

## 5. 词卡浮窗
点击已标注的词，可能弹出词卡。

1. 可做「记得 / 模糊 / 忘了」一类复习操作（需 Weave 复习能力）。
2. 设置中可开关「显示复习间隔」，在按钮上方预估下次复习时间。
3. 也可在词卡右键菜单中开关间隔显示。
