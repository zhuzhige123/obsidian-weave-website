阅读计划从目录生成带日期的任务行，复制后粘贴到任意笔记，即可被 Weave Review「重要日程」识别与推进。适合把一本书拆成按天阅读的日程，而不把排程逻辑锁死在阅读器内部。本能力为高级支持。以下是详细介绍：

## 1. 从目录打开
1. 打开一本书，显示侧栏「目录」。
2. 在某一章上打开菜单。
3. 「加入阅读计划」：以当前章为起点生成计划（具体以对话框为准）。
4. 「从本章起生成阅读计划」：从该章排到目录后方，适合长书分段。

>备注：未开通时会提示这是高级功能（界面文案可能写作「重要日程」）。未安装 Weave Review 时，仍可先复制任务行到笔记；识别与日程视图依赖 Weave Review 重要日程能力。

## 2. 配置项
生成对话框里常见选项：

1. **起始日期**：计划从哪一天开始。
2. **指定每天时刻**：是否给每天固定一个钟点；开启后再选「每天时刻」。
3. **间隔天数**：隔几天排一次（例如每天 = 1）。
4. **每次章节数**：一天（或一次）排几章。
5. **跳过周末**：是否避开周六日。
6. **结束方式**：
   - 「排到目录末尾」
   - 「最多排 N 章」
   - 「最多排 N 天」
7. 选「最多排 N 章 / 天」时，再填对应上限。

配置变化时，预览中的任务块会跟着更新。

## 3. 复制到笔记
1. 预览区会显示任务行摘要，例如共多少条、起止日期。
2. 点「复制」，把全部任务行拷到剪贴板。
3. 打开任意 Markdown 笔记，粘贴到合适位置。
4. 若当前配置不会生成任何任务，预览会提示为空，请调整日期、间隔或结束方式后再复制。

>备注：阅读器生成的是可粘贴的任务文本，不会强制改写你的某份固定计划文件。你可以贴进读书笔记、日程页或专题页。

## 4. 和增量阅读怎么选
1. **阅读计划 / 重要日程**：按日历推进「哪天读哪几章」，任务落在笔记里。
2. **增量阅读**：把章节送进增量阅读队列与月历精读节奏。见 `Er-04c 与 Weave Review 制卡、增量阅读、AI 联动`。
3. 可以只用其中一种，也可以目录里两种入口都用——看你是偏日程任务，还是偏阅读点队列。

## 5. 常见提示
1. 「当前没有打开的书籍」：先打开书再从目录生成。
2. 「没有可排程的章节」：目录为空或起点之后没有可排章，换一章再试。
3. 复制失败：按提示手动选中预览文本复制。
4. 生成失败：关闭对话框重试；仍失败时确认目录已加载完成。
