阅读器侧栏可以把当前书的摘录收成一张张卡片，也可以按日期看整座书架上的摘录脉络。列表适合整理一本书；时间线适合回看最近几天跨书摘了什么。以下是详细介绍：

## 1. 打开本书摘录列表
1. 打开一本书，显示侧边栏。
2. 切到「摘录」标签。
3. 列表会加载本书已索引到的高亮与想法。
4. 暂时没有摘录时，会提示：阅读时选中文本后就可以在这里回看。


## 2. 列表卡片上能做什么
每条摘录卡片通常可：

1. 查看摘录正文与想法。
2. 点击后定位到书中原文。
3. 「跳转到笔记」，打开保存该条的 Markdown 等文件。
4. 删除单条摘录（会按确认提示处理）。


## 3. 筛选与搜索
摘录多了之后，可用侧栏搜索。

1. 直接输入关键词，匹配摘录内容。
2. 也可使用属性前缀，例如 `tag:`、`source:`、`comment:`、`type:`、`color:`、`chapter:`。
3. 可按想法状态、笔记类型、高亮颜色等收窄结果。
4. 没有匹配时，会提示尝试调整这些条件。


## 4. 排序
在摘录为「列表卡片」显示时，可切换排序。

1. 书中位置：从前到后，或从后到前。
2. 创建时间：从新到旧，或从旧到新。

>备注：按书中位置浏览，适合顺章节复习；按创建时间浏览，适合回看「昨天划了什么」。

## 5. 列表与时间线视图
本书摘录区可在两种展示之间切换。

1. 「列表卡片」：一条一条卡片，适合筛选和批量操作。
2. 「时间线视图」：按日期回顾本书摘录。


## 6. 批量选择、导出与删除
在列表中可进入批量选择。

1. 打开菜单「批量选择」，勾选多条。
2. 「全选当前结果」或「取消全选」。
3. 「导出所选摘录」或「导出当前筛选结果」。导出细节见 `Er-04a 导出笔记与模板`。
4. 「删除所选摘录」前会确认条数。

>备注：删除摘录可能同时影响书中回显。重要内容请先确认笔记里是否还有副本。

## 7. 全书架时间线
命令面板可执行「全书架时间线」，或在侧栏打开对应视图。

1. 按日期浏览书架上各书的摘录。
2. 适合回顾一段时间的阅读轨迹，而不必一本一本点开。
3. 点击条目可尝试跳回原文。
4. 未开通时会提示这是高级功能。
