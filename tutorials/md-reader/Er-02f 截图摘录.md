截图摘录用于没法干净划词的内容：插图、复杂版式、跨页表格、漫画分格等。可以框选一页上的区域，必要时翻页继续截，并选择保存为图片文件或嵌入链接。以下是详细介绍：

## 1. 打开截图工具
1. 打开一本书。
2. 用顶部功能键或菜单打开「截图工具」。
3. 开启后，可在页面上拖出选区。
4. 用完后再次关闭，以免影响普通划词。

>备注：截图工具与自动插入可配合：开启自动化时，截图结果会按当前笔记或 Canvas 规则输出。

## 2. 保存方式
菜单或功能键中有「截图保存为图片」。

1. **保存为图片文件（开）**：把截图写入库中的图片文件，便于在笔记里用 `![]()` 引用。
2. **保存为嵌入链接（关）**：按嵌入链接方式写入当前笔记，具体格式以插入结果为准。
3. 也可先复制图片到剪贴板，再粘贴到其它位置。

>备注：需要长期归档、多处引用同一张图时，保存为独立图片文件更清楚。

## 3. 翻页续截
一页截不完时，可在截图过程中翻到下一页继续。

1. 先框选当前页需要的部分。
2. 翻页后再框选后续部分（以界面提示为准）。
3. 完成后一并写入笔记或保存图片。


## 4. 与划词摘录的关系
1. 划词：得到可搜索的文字 + 溯源链接，适合观点与金句。
2. 截图：得到图像，适合版式本身就是信息的情况。
3. 两者都可带书籍定位，便于从笔记回到附近页。
4. 截图不会替代文字高亮列表里的每一条，侧栏摘录仍以文字摘录为主。


## 5. 常见提示
1. 「截图已保存」会带上文件名，可到库中确认位置。
2. 复制图片失败时，改用保存为文件再插入。
3. 未找到活动 Markdown 编辑器时，先打开笔记再截。
