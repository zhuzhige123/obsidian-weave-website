目录上的彩色圆点用来标记整章状态，例如重点、有疑问、已掌握。全书地图密度条则用条带示意各章摘录有多密，方便找「划得最多」的地方。两项均为高级支持。以下是详细介绍：

## 1. 标记章节
1. 打开侧栏「目录」。
2. 在章节上打开菜单，选择「标记章节」。
3. 可选「重点」「有疑问」「已掌握」，或与增量阅读相关的标记（若已安装增量阅读插件）。
4. 「清除标记」去掉该章圆点。
5. 保存失败时按提示重试，不要连续狂点。


## 2. 圆点语义设置
若默认的「重点 / 疑问 / 已掌握」不符合你的习惯，可改语义与颜色。

1. 打开「圆点语义设置」。
2. 为各标记选择颜色，必要时改含义（以设置窗为准）。
3. 可恢复默认。
4. 保存后，目录圆点按新约定显示。


## 3. 全书地图密度条
1. 在目录相关菜单中开启「显示全书地图密度条」。
2. 侧栏会以密度条概览全书摘录分布。
3. 摘录越多的章，条带会更醒目（具体样式以界面为准）。
4. 便于复习时先跳到「划得密」的章节。


## 4. 与上次阅读位置
目录中可能标出「上次阅读」「当前阅读位置」。

1. 用来快速回到续读处。
2. 与圆点标记互不替代：一个是进度，一个是你对该章的判断。
