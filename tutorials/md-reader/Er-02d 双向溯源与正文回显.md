双向溯源让笔记、Canvas、卡片与原书互相跳转：在笔记里点书籍图标回到句子，在书里点高亮跳到来源笔记。精确定位属于高级支持；未开通时，仍可阅读与做基础摘录，但点链接可能无法精确落到原句。以下是详细介绍：

## 1. 溯源链接从哪来
按 `Er-02a 摘录笔记工作流` 把摘录插入 Markdown、Canvas 或牌组后，条目里会带上书籍定位信息。

1. 阅读器据此在正文画出回显高亮。
2. 笔记里会出现可点击的书籍图标或链接。
3. 同一条摘录改颜色、补想法后，回显会尽量同步。

>备注：没有溯源字段的纯复制文本，只是普通摘抄，阅读器无法用来跳转或回显。

## 2. 从书跳到笔记
1. 点击正文中的高亮。
2. 在工具条中选择跳转到笔记。
3. Obsidian 会打开保存该摘录的 Markdown 等文件，并尽量滚到对应段落。

>备注：若一条摘录被多处引用，可能看到来源列表，再选要打开的那一篇。

## 3. 从笔记跳回原书
1. 在保存摘录的笔记中，点击摘录旁的书籍图标或深链接。
2. 阅读器打开对应图书，并尝试滚到原句。
3. Canvas 节点上的回链同样可用来回到书中。
4. Weave Deck 卡片若带有阅读器溯源，也可从学习界面跳回。见 `We-01a 新建卡片` 中的来源字段说明。

>备注：精确定位可能提示需激活高级支持。未激活时，可能只打开书、落不到原句。

## 4. 适用格式
溯源面向阅读器支持的多种格式，包括 EPUB、MOBI、TXT、CBZ 等。

1. 不同格式的内部定位方式不同，但使用上仍是「点链接回去」。
2. PDF 使用 Obsidian 自带查看器，跳转能力与 EPUB 不完全相同。
3. 图书文件被移动或改名后，旧链接可能失效，需重新摘录或检查路径。

>备注：保持图书文件在 Vault 内路径稳定，溯源会更省心。

## 5. 旧式链接迁移
若笔记里仍是旧版「URL 内嵌全文」的长链接，编辑会很别扭。

1. 打开相关笔记时，可能提示缩短 EPUB 溯源链接。
2. 确认后会去掉链接中的正文参数并压缩定位信息。
3. callout 里引用的正文本身不会被改掉。
4. 可选择暂不迁移，改日再处理。

>备注：迁移只动链接结构，不改你写的想法文字。建议先确认笔记已备份或可由同步恢复。

## 6. 回显不出现时
1. 确认摘录已写入库文件，而不是只在剪贴板。
2. 确认图书仍在原路径，书架能打开同一本书。
3. 关闭再打开阅读器，让索引重新扫描。
4. 检查是否误删了笔记中带链接的那一段。
