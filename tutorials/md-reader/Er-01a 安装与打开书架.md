Weave Reader 是 Obsidian Weave 插件系列里的阅读器。它在 Obsidian 里打开 EPUB、TXT、FB2/FBZ、MOBI、AZW3、CBZ、PDF 等图书，用「我的书架」管理导入、封面、进度与阅读状态。可单独使用；安装 Weave Review 后，还能衔接制卡、增量阅读与 AI。以下是详细介绍：

## 1. 安装与启用
推荐从社区插件市场安装。

1. 打开 Obsidian **设置 → 社区插件 → 浏览**。
2. 搜索 **Weave Reader**，安装并启用。
3. 启用后，左侧功能区会出现书架图标。点击即可打开「我的书架」。
4. 也可在命令面板中执行「我的书架」。

>备注：最低 Obsidian 版本为 1.8.7。桌面端与移动端均可使用。

## 2. 手动安装
若暂时无法使用社区市场，可从 GitHub 发布包手动安装。

1. 下载与 `manifest.json` 版本号一致的发布包，取得 `main.js`、`manifest.json`、`styles.css`。
2. 复制到库目录 `.obsidian/plugins/weave-epub-reader/`。
3. 重启 Obsidian，在 **设置 → 社区插件** 中启用 **Weave Reader**。

>备注：手动安装时，三个文件需放在同一插件文件夹内，且版本互相匹配。

## 3. 支持的书籍格式
书架可收录并打开下列格式。图书文件需先放进当前 Vault。

1. 阅读器自有界面打开：EPUB、TXT、FB2 / FBZ、MOBI、AZW3、CBZ。
2. PDF 会出现在书架中，但用 Obsidian 自带 PDF 查看器打开，不是阅读器自绘正文。
3. TXT 会按段落分章，便于目录跳转。

## 4. 打开书架并加入图书
第一次使用时，书架通常是空的。常用有两种加入方式：**扫描库内文件**，或**从仓库外直接导入**。

1. 点击功能区书架图标，或执行命令「我的书架」。
2. 空书架会提示：还没有书籍或漫画，可先扫描库中文件并加入。
3. **扫描 Vault**：点击「扫描 Vault 添加书籍」，或打开菜单中的「扫描仓库书籍和漫画」；在结果中勾选要加入的文件。已在书架中的项会提示已添加。
4. **从仓库外导入**：在书架菜单选择「从仓库外导入书籍」，用系统文件选择器挑选本机上的 EPUB / TXT / MOBI 等；插件会把文件复制进 Vault 指定位置并加入书架。可一次多选。
5. 加入成功后，封面、书名、进度会出现在书架中。

>备注：首次打开书架时，可能看到引导页，介绍多格式阅读、书架视图、阅读版式、摘录回链等能力，并提供官网与阅读器教程入口。仓库外导入适合书还在下载文件夹、尚未放进库的场景；书目仍由你勾选加入，不会自动把全库扫进书架。

## 5. 书架显示方式
书架支持多种展示，默认为「跟随位置」。可在书架菜单或设置中切换。

1. 「跟随位置」：侧边栏用阅读月历；主内容区进入书架主页（见下一节）。
2. 「阅读月历」：按月份浏览书架时间线（如「九月」分组），回顾阅读足迹。
3. 「卡片网格」：封面与关键信息（作者、进度等）一并显示。
4. 「横幅卡片」：横向封面横幅，展示阅读状态与进度（高级）。
5. 「仅看封面」：纯封面书墙，少信息、多浏览（高级）。

>备注：侧边栏与主内容区适合不同宽度；「跟随位置」会按所在位置自动选用更合适的形态，而不必离开主页壳。

## 6. 内容区书架主页
把书架放到 Obsidian **主内容区**时，会进入书架主页，而不是单纯的窄栏列表。

1. 顶栏可在「书架 / 笔记 / 统计」之间切换（移动端也可能用顶栏圆点切换）。
2. 「书架」页：状态、排序与筛选，书单快捷入口；底栏可看最近阅读。显示方式只切换主页内的卡片 / 月历等样式。
3. 「笔记」页：全书架摘录时间线入口（高级；未开通时会提示）。
4. 「统计」页：最爱书籍、个人阅读画像、完成足迹与年度热力图等汇总（高级；可能限时开放）。
5. 书架顶部还可选开「继续阅读」信息卡，或书架活动热力日历（高级；热力与信息卡通常互斥）。

>备注：侧边栏打开书架时，更适合用阅读月历快速找书；需要统计与全书架笔记脉络时，把书架拖到主内容区即可。按主题收纳多本书，见 `Er-01d 书架书单`。

## 7. 打开一本书
加入书架后即可开始阅读。

1. 点击书名或封面，打开阅读器。
2. 需要并排对照时，可在书籍菜单中选择「在新标签页打开」。
3. 若当前正在看 Vault 里的一本支持格式图书，也可在命令面板执行「打开 Weave Reader」。
4. 源文件被移动或删除时，刷新书架会清理失效记录，并可能提示已从书架移除。

## 8. 书籍菜单常用操作
在书架书籍上打开菜单，可做日常整理。

1. 「查看书籍完整信息」：查看作者、字数、章节数等。
2. 「重命名」：同步用于书架、阅读器标签与书签笔记。
3. 「标记为已读完」或取消该标记。
4. 「自定义书籍封面」：选用库中图片，或恢复内置封面。
5. 「从书架中移除」：只从书架拿掉，不删除库中的书。
6. 「删除书籍文件」：删除库中的图书文件；摘录笔记仍留在原来的 Markdown 等文件里。

## 9. 搜索与筛选
图书较多时，可用顶部搜索。

1. 直接输入书名等关键词。
2. 也可使用属性前缀，例如 `status:`、`author:`、`created:`。
3. 阅读状态包括「未开始」「阅读中」「已读完」。

## 10. 与 Weave Review 的关系
阅读器可以独立完成阅读、书架与基础摘录。

1. 不安装 Weave Review，也能阅读、管理书架，并把摘录写入 Markdown / Canvas。
2. 安装 Weave Review 后，可选衔接制卡复习、增量阅读、AI 菜单，以及把摘录写入牌组。
3. 若已激活 Weave Review，阅读器高级支持可继承授权，不必再单独输入阅读器激活码。
