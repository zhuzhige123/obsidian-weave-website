Weave EPUB Reader 是 Obsidian Weave 插件系列里的阅读器。它在 Obsidian 里打开 EPUB、TXT、FB2/FBZ、MOBI、AZW3、CBZ、PDF 等图书，用「我的书架」管理导入、封面、进度与阅读状态。可单独使用；安装 Weave 主插件后，还能衔接制卡、增量阅读与 AI。以下是详细介绍：

## 1. 安装与启用
推荐从社区插件市场安装。

1. 打开 Obsidian **设置 → 社区插件 → 浏览**。
2. 搜索 **Weave EPUB Reader**，安装并启用。
3. 启用后，左侧功能区会出现书架图标。点击即可打开「我的书架」。
4. 也可在命令面板中执行「我的书架」。

>备注：最低 Obsidian 版本为 1.8.7。桌面端与移动端均可使用。

## 2. 手动安装
若暂时无法使用社区市场，可从 GitHub 发布包手动安装。

1. 下载与 `manifest.json` 版本号一致的发布包，取得 `main.js`、`manifest.json`、`styles.css`。
2. 复制到库目录 `.obsidian/plugins/weave-epub-reader/`。
3. 重启 Obsidian，在 **设置 → 社区插件** 中启用 **Weave EPUB Reader**。

>备注：手动安装时，三个文件需放在同一插件文件夹内，且版本互相匹配。

## 3. 支持的书籍格式
书架可收录并打开下列格式。图书文件需先放进当前 Vault。

1. 阅读器自有界面打开：EPUB、TXT、FB2 / FBZ、MOBI、AZW3、CBZ。
2. PDF 会出现在书架中，但用 Obsidian 自带 PDF 查看器打开，不是阅读器自绘正文。
3. TXT 会按段落分章，便于目录跳转。


## 4. 打开书架并加入图书
第一次使用时，书架通常是空的。

1. 点击功能区书架图标，或执行命令「我的书架」。
2. 空书架会提示：还没有书籍或漫画，可先扫描库中文件并加入。
3. 点击「扫描 Vault 添加书籍」，或打开菜单中的「扫描仓库书籍和漫画」。
4. 在结果中选择要加入的文件。已在书架中的项会提示已添加。
5. 加入成功后，封面、书名、进度会出现在书架列表或网格中。


## 5. 书架显示方式
书架支持多种展示，适合宽屏、侧边栏或只看封面。

1. 「列表详情」：突出书名、作者、标签和进度。
2. 「卡片网格」：显示封面与关键信息。
3. 「仅看封面」：纯封面书墙。
4. 「跟随位置」：侧边栏用列表，主内容区用卡片网格。


## 6. 打开一本书
加入书架后即可开始阅读。

1. 点击书名或封面，打开阅读器。
2. 需要并排对照时，可在书籍菜单中选择「在新标签页打开」。
3. 若当前正在看 Vault 里的一本支持格式图书，也可在命令面板执行「打开 EPUB 阅读器」。
4. 源文件被移动或删除时，刷新书架会清理失效记录，并可能提示已从书架移除。


## 7. 书籍菜单常用操作
在书架书籍上打开菜单，可做日常整理。

1. 「查看书籍完整信息」：查看作者、字数、章节数等。
2. 「重命名」：同步用于书架、阅读器标签与书签笔记。
3. 「标记为已读完」或取消该标记。
4. 「自定义书籍封面」：选用库中图片，或恢复内置封面。
5. 「从书架中移除」：只从书架拿掉，不删除库中的书。
6. 「删除书籍文件」：删除库中的图书文件；摘录笔记仍留在原来的 Markdown 等文件里。


## 8. 搜索与筛选
图书较多时，可用顶部搜索。

1. 直接输入书名等关键词。
2. 也可使用属性前缀，例如 `status:`、`author:`、`created:`。
3. 阅读状态包括「未开始」「阅读中」「已读完」。


## 9. 与 Weave 主插件的关系
阅读器可以独立完成阅读、书架与基础摘录。

1. 不安装 Weave，也能阅读、管理书架，并把摘录写入 Markdown / Canvas。
2. 安装 Weave 后，可选衔接制卡复习、增量阅读、AI 菜单，以及把摘录写入牌组。
3. 若已激活 Weave 主插件，阅读器高级支持可继承授权，不必再单独输入阅读器激活码。
