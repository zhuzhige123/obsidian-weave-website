obsidian weave 支持在普通 Markdown 笔记中嵌入「牌组学习视图」。你可以在编辑器里通过右键菜单，把选中的记忆牌组插入为 `weave-decks` 代码块；笔记渲染后，会直接显示牌组卡片，并从这里开始学习。适合把学习入口写进课程笔记、复习清单、专题页或仪表盘。以下是详细介绍：

## 功能概述

嵌入的牌组视图，本质上是把插件「牌组学习」里的牌组卡片，搬到当前笔记页面里展示。

1. 显示的是**记忆牌组**，不是考试题组。
    
2. 每个牌组卡片上，仍能看到待学数量、学习状态等信息，并可直接点击开始学习。
    
3. 插入后得到的是笔记里的代码块；Obsidian 进入阅读模式或实时预览时，代码块会渲染成可视化的牌组网格。
    
4. 这与打开插件主窗口进入牌组学习，是两种入口：主界面适合集中管理；笔记嵌入适合把学习入口放在你正在阅读或整理的文档旁边。
    

> 备注：插件主界面拖到侧边栏时的「位置自适应」，改的是主窗口怎么展示；本文介绍的是把牌组视图写进 md 笔记正文。

## 通过编辑器右键插入

最常用的插入方式，是在 Markdown 编辑器中通过 Weave 右键菜单完成。

1. 打开任意 Markdown 笔记，并把光标放在希望插入的位置。
    
2. 在编辑区**右键**，打开 Obsidian 编辑器菜单。
    
3. 找到 **Weave 操作**，进入其子菜单。
    
4. 选择 **插入牌组视图**，会展开牌组选择列表。
    
5. 在列表中勾选要显示的牌组；可多次点按切换勾选状态。
    
6. 选好后，点击 **插入到当前笔记**。
    
7. 插件会在光标处插入一段 `weave-decks` 代码块，并提示已插入多少个牌组。
    

> 备注：若尚未创建任何记忆牌组，子菜单可能显示「暂无可用牌组」。请先到插件「牌组学习」界面创建牌组后再试。

## 牌组选择子菜单

「插入牌组视图」子菜单里，除了牌组列表，还有几项辅助操作。

1. **牌组列表**：列出当前库中的记忆牌组；名称前带勾选标记的，表示已选中。
    
2. **全选**：一次性选中全部可用记忆牌组。
    
3. **清除选择**：清空当前勾选，便于重新挑选。
    
4. **插入到当前笔记**：按当前勾选结果，生成代码块并写入笔记。
    

插件会记住你上次勾选过哪些牌组。下次再打开同一子菜单时，通常会恢复上次的勾选状态，方便反复往不同笔记里插入同一组牌组。

> 备注：若点击「插入到当前笔记」时没有任何牌组被勾选，界面会提示「请先在子菜单中勾选要显示的牌组」。

## 插入后生成的代码块

插入成功后，笔记中会出现类似下面结构的代码块：

```weave-decks
title: 我的牌组
size: medium
deckNames:
  - 牌组A
  - 牌组B
sort: due
limit: 6
```

各字段含义如下：

1. **title**：嵌入区域上方显示的标题；不需要时可留空或删除该行。
    
2. **size**：牌组卡片尺寸，可选 `small`（小）、`medium`（中）、`large`（大）；也支持简写如 `s` / `m` / `l`，或中文「小」「中」「大」。
    
3. **deckNames**：要显示的牌组名称列表；名称须与插件中的记忆牌组名称一致。
    
4. **sort**：排序方式。`due` 表示按待复习数量优先；`name` 表示按名称排序。
    
5. **limit**：最多显示多少个牌组；例如 `6` 表示只展示前 6 个符合条件的牌组。
    

> 备注：你也可以不通过右键，而是手动在笔记里编写上述代码块；右键插入的作用是自动生成模板，并填好已勾选牌组名称。

## 笔记中的显示效果

当 Obsidian 渲染该笔记时，代码块会变成实际的牌组卡片网格。

1. 若设置了 **title**，会在牌组卡片上方显示标题。
    
2. 每个牌组以卡片形式展示，样式跟随插件设置中的「牌组卡片样式」（如「默认」「国风雅致」）。
    
3. 卡片上会显示牌组名称、待学/复习等学习状态信息，与主界面牌组学习中的网格卡片一致。
    
4. 若某个牌组名称写错、已被删除，或当前没有符合条件的牌组，可能显示「没有找到可显示的牌组」。
    
5. 数据尚未加载完成时，可能短暂显示「正在加载牌组...」。
    

> 备注：嵌入视图展示的是**牌组入口**，不是单张记忆卡的列表。若要管理具体卡片，仍需进入插件「卡片管理」。

## 在嵌入视图中开始学习

嵌入后的牌组卡片，并不只是展示，也可以直接操作。

1. 点击牌组卡片，即可像在主界面一样**开始学习**该牌组。
    
2. 在牌组卡片上打开菜单，还可进行编辑、提前学习、分析、导出等操作；具体项与主界面牌组卡片菜单一致。
    
3. 学习过程会进入正常的记忆学习界面；完成后返回笔记，嵌入视图仍在原位置。
    

> 备注：记忆学习界面内部的评分、工具栏与更多操作，见 `We-02c 记忆学习界面`。

## 手动调整嵌入内容

插入后若需微调显示范围或外观，可直接编辑代码块，无需重新走一遍右键流程。

1. **只显示部分牌组**：修改 `deckNames` 列表，保留需要的名称即可。
    
2. **改变卡片大小**：把 `size` 改为 `small`、`medium` 或 `large`。
    
3. **优先显示最该复习的牌组**：将 `sort` 设为 `due`，并配合 `limit` 控制显示数量。
    
4. **给专题页加标题**：修改 `title`，例如改成「本周复习」「第三章配套牌组」。
    
5. 保存笔记后，Obsidian 重新渲染即可看到变化。
    

若牌组刚创建或刚重命名，但嵌入区仍找不到，请优先检查 `deckNames` 是否与当前牌组名称完全一致。

## 典型使用场景

可按笔记组织方式灵活使用：

1. **课程/章节笔记**：在每章笔记末尾插入对应牌组，读完一章就能顺手开练。
    
2. **复习仪表盘**：单独建一篇「今日复习」笔记，用 `sort: due` 和 `limit` 集中显示最该学的几个牌组。
    
3. **专题汇总页**：同一主题下多个牌组，用一次插入或手动维护 `deckNames` 列表统一展示。
    
4. **Obsidian 主页或导航页**：把常用牌组嵌进入口笔记，减少来回切换插件主界面的次数。
    

## 与主界面牌组学习的关系

两者互补，可按习惯组合使用。

| 对比项 | 笔记嵌入牌组视图 | 插件主界面 · 牌组学习 |
|--------|------------------|------------------------|
| 入口 | Markdown 笔记中的代码块 | 插件主窗口 |
| 适合 | 把学习入口写在文档里 | 集中浏览、创建、管理全部牌组 |
| 视图 | 网格卡片 | 看板 / 网格（可随位置自适应） |
| 题组 | 不支持嵌入考试题组 | 可切换到考试题组模式 |

> 备注：牌组学习主界面的创建、看板列设置、位置自适应等，见 `We-02a 牌组学习界面`。考试题组见 `We-02d 考试题组`。

## 常见问题

**Q：为什么列表里没有某个牌组？**  
A：嵌入功能目前只支持**记忆牌组**；考试题组不会出现在「插入牌组视图」列表中。

**Q：插入后显示「没有找到可显示的牌组」？**  
A：通常是 `deckNames` 与真实牌组名称不一致，或牌组已被删除、重命名。请对照插件牌组学习界面中的名称修改代码块。

**Q：能否在 Excalidraw、Canvas 或其他非 Markdown 页面插入？**  
A：本功能面向 Markdown 编辑器右键菜单；需在 `.md` 笔记中使用 `weave-decks` 代码块。

**Q：嵌入视图会和主界面样式不一致吗？**  
A：牌组卡片样式跟随插件设置中的「牌组卡片样式」；修改设置后，主界面与笔记嵌入区会一起更新。
