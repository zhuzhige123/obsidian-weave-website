obsidian weave 主界面中的批量解析，适用于笔记里已经按固定版式写好多张卡片内容，希望按规则一次性拆分、先预览再导入牌组。它不调用大模型，而是依据你在插件中配置的解析模板（分隔符或正则）读取 Markdown，把匹配到的条目整理成待确认卡片。适合 AI 对话导出、规范制卡稿、分隔线分块笔记等场景。以下是详细介绍：

## 进入解析预览

批量解析入口在「AI 制卡」页的「解析预览」子视图中，与「AI 制卡」共用同一主界面，但流程彼此独立。

1. 打开插件主界面，通过左上角菜单切换到「AI 制卡」。
    
2. 切换到「解析预览」。桌面端可通过左侧功能键切换；移动端也可通过顶部彩色圆点中的蓝点进入。
    
3. 进入后，顶栏会显示「文件/文件夹」与「解析模板」；右上角主操作为「开始解析」。
    

> 备注：口语里的「批量解析」多指本页的「解析预览 → 勾选 → 导入」。它与 `We-01h AI制卡` 中的 AI 生成不是同一路径，也不要求配置 AI 服务。

## 使用前准备

开始解析前，需要先有可用的解析模板，并准备好版式匹配的 Markdown 源文件。

1. 确认插件中至少保存了一个解析模板；若列表为空，需先到「解析预览配置」中创建或导入预设。
    
2. 准备作为输入的 Markdown 笔记，正文结构应与所选模板一致，例如按 `<->` 分卡、用 `---div---` 分正反面，或符合某套 Q/A 正则版式。
    
3. 若尚未创建记忆牌组，建议先到「牌组学习」界面创建一个，便于后续导入。
    

> 备注：解析能否成功，主要取决于「笔记版式」与「模板规则」是否一致，而不是 AI 是否可用。版式不对时，可能解析失败或结果为空。

## 解析预览配置

分隔符、正则模板、批量扫描范围等，集中在「解析预览配置」里管理。

1. 处于「解析预览」时，点击左上角菜单，选择「解析预览配置」。
    
2. 在「符号与分隔符」区域，可查看或调整卡片区间分隔符、正反面分隔符等全局符号；这些符号会参与部分模板的分卡逻辑。
    
3. 在「正则解析模板」区域，可新建、编辑、复制或删除模板；插件也内置官方示例模板，可按名称导入后微调。
    
4. 编辑模板时，可使用「测试解析」在保存前用示例 Markdown 验证规则是否匹配；也可查看官方示例文档，对照自己的笔记格式。
    
5. 若需批量扫描文件夹，还可在配置中设置排除文件夹、单次最多处理的文件数等批量相关选项。
    

> 备注：解析预览配置可能属于高级功能。若打开后提示需要开通，按插件提示处理即可。已有内置模板时，通常可先直接选用，再按需进入配置修改。

## 选择源文件或文件夹

解析预览支持单篇笔记，也支持选中文件夹后批量读取其中的 Markdown。

1. 点击顶栏「文件/文件夹」。
    
2. 选择「选择文件」，从库中搜索并选中一篇 Markdown；或选择「选择文件夹」，指定某个文件夹作为扫描范围。
    
3. 选文件夹时，插件会递归读取其中的 Markdown 文件，并受配置中的排除目录与单次文件数上限约束。
    
4. 选中后，功能栏会显示当前来源；插件也会记住你上次的选择。
    

> 备注：AI 制卡模式通常只处理单篇笔记；解析预览才支持「整文件夹批量读取」。所选文件会作为卡片溯源文档记录，但通常不会精确到块级位置。

## 选择解析模板

每次解析前，都需要在顶栏指定一套模板规则。

1. 点击顶栏「解析模板」，从已保存预设中选择其一。
    
2. 若列表为空，请先到「解析预览配置」中创建模板，再回到本页选择。
    
3. 不同模板对应不同分卡方式，例如分隔符切分、正则匹配等；应选与当前笔记结构最相符的一项。
    

> 备注：模板名称会显示在预览区标题旁，便于确认当前使用的是哪套规则。

## 开始解析

来源与模板都准备好后，即可发起解析。

1. 确认已选择源文件或文件夹，且已选定解析模板。
    
2. 点击右上角「开始解析」。
    
3. 解析过程中，界面会停留在解析预览区；完成后会把拆分结果展示在预览列表中。
    
4. 单文件解析成功后，通常会提示解析出的卡片张数；文件夹模式下，还会汇总处理了多少个文件。
    
5. 若部分文件失败，通知中可能附带失败文件数量或原因，已成功解析的卡片仍会进入预览。
    

> 备注：若文件夹内没有可解析的 Markdown，或版式与模板不匹配导致一张都拆不出来，界面会提示解析失败或结果为空。此时应先检查模板与笔记范例是否一致。

## 预览与挑选卡片

解析完成后，先在预览区检查每条的正反面与标签，再决定哪些卡片入库。

1. 主预览区展示当前卡片的正反面，可像正常学习卡片一样查看内容。
    
2. 预览标题旁会显示来源摘要；单文件时多为文件名，文件夹批量时可能显示「文件夹 · N 个文件 · M 张卡 · 模板名」一类信息。
    
3. 若结果来自多文件批量解析，切换卡片时还可能看到当前条目对应的来源文件名。
    
4. 底部序号条用于切换卡片；点按序号可跳转，长按序号可选中或取消选中。
    
5. 解析出的卡片默认处于选中状态；不需要的可在序号条上长按取消，或使用「全选 / 取消全选」。
    

> 备注：预览区改变的是「是否导入」，不会改写源笔记。若某张卡结构异常，导入时可能有提示或失败，可先取消勾选该张。

## 导入到牌组

确认无误后，将勾选的卡片写入目标牌组。

1. 在预览区底部选择「目标牌组」。
    
2. 确认右下角导入按钮上显示的数量，即为当前勾选张数。
    
3. 点击「导入 N 张」执行入库。
    
4. 成功后，界面会给出摘要提示；已导入的卡片会自动从待导入勾选里移除。
    

> 备注：导入前至少需勾选一张卡片，并选定有效牌组。解析结果不会走 AI 制卡的「历史记录」恢复机制；若需再次导入，通常应重新解析或保留当前预览状态。

## 侧边栏模式与跟随当前文档

把解析预览页放到 Obsidian 侧边栏时，选来源的方式会略有不同。

1. 将插件主界面拖到侧边栏后，界面会切换为更适合窄栏的布局。
    
2. 此时顶栏文件入口可切换为「跟随当前文档」，配合中间正在打开的 Markdown 作为单文件来源。
    
3. 开启后，你在内容区切换笔记时，解析预览会跟随当前打开的 Markdown；关闭后恢复手动选文件。
    
4. 若当前选择的是「文件夹」批量来源，则不会跟随单篇活动文档切换，仍以文件夹为准。
    

> 备注：跟随当前文档适合「边整理边解析单篇制卡稿」；需要一次处理整个目录时，应改用「选择文件夹」。

## 与 AI 制卡的区别

同一页面里还有「AI 制卡」子视图，两者容易混淆，可按下面方式选用。

| 对比项 | 解析预览（批量解析） | AI 制卡 |
|--------|----------------------|---------|
| 是否调用大模型 | 否 | 是 |
| 主要依赖 | 解析模板与笔记版式 | AI 配置、模型、提示词 |
| 典型输入 | 单文件或文件夹 | 单篇笔记 |
| 典型适用 | 材料已是准卡片结构 | 材料杂乱、需要理解与改写 |
| 先学后入库 | 不支持「立即学习」筛选 | 支持 |

> 备注：若笔记还没有稳定版式，优先用 `We-01h AI制卡`；若已是规范制卡稿、AI 导出结果或分隔线分块文档，优先用本文的解析预览。

## 与命令面板旧入口的关系

较早版本里，Obsidian 命令面板中曾有「批量解析当前文件」等命令。当前主路径已统一到本页的「解析预览」：先选来源与模板，预览确认后再导入。

1. 若你习惯「先看一眼再决定入不入库」，应使用本文介绍的解析预览流程。
    
2. 若在其他教程或旧笔记里仍看到命令面板批量解析字样，请以当前软件内的「AI 制卡 → 解析预览」为准。
    

> 备注：解析规则来自同一套模板体系；变化的是入口与后续是否需要预览确认。卡片格式规范见 `We-01g 卡片题型`。
