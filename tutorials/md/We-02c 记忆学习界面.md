obsidian weave的记忆学习界面，是真正开始复习记忆卡片的地方。从牌组学习进入后，按「看题 → 显示答案 → 评分」循环推进，直到本场学完。以下是详细介绍：

## 记忆学习界面
该功能适用于从某个记忆牌组开始本场复习。

1. 打开插件主界面，进入牌组学习界面，并切换到记忆牌组。
2. 点击目标牌组卡片，即可进入记忆学习界面。
3. 若该牌组今天已学完、当前没有到期卡，或牌组还是空的，会先弹出提示窗，而不是直接进入学习。
4. 无卡可学时，可按提示选择提前学习、查看统计等后续操作。
5. 也可在牌组菜单中选择「提前学习」，把尚未到期、但仍在可提前范围内的卡片一并学掉。

>备注：记忆学习界面与牌组学习界面不同。牌组学习负责选哪个牌组开练；记忆学习负责一张张复习并评分。

## 界面布局
进入后，界面大致分成几块，先认位置再操作更顺。

1. 顶部：显示当前牌组名称，以及本场进度，例如当前第几张 / 一共多少张。
2. 中间：显示当前卡片内容。未显示答案时，通常先看正面或题干；显示答案后，会看到背面、解析或挖空答案等。
3. 底部：先是「显示答案」或「确认答案」，揭开后再出现「重来」「困难」「良好」「简单」四个评分键。
4. 右侧：是学习工具栏，可编辑、删除、设置提醒与优先级、查看卡片信息，以及打开更多设置。移动端这些能力更多收进顶部菜单。

>备注：先把「中间看内容、底部做评分、右侧做辅助」记住，后面大部分操作都落在这三块。

## 内容预览与编辑
记忆学习界面中的卡片内容预览，以及点开后的编辑体验，都沿用 Obsidian 官方能力，而不是另做一套独立编辑器。

1. 预览时，你看到的是接近 Obsidian 原生的内容渲染效果。
2. 编辑时，使用的也是 Obsidian 官方编辑体验，可按 Markdown 习惯直接改内容。
3. 正因为走的是官方渲染与编辑链路，所以能兼容大部分 Obsidian 插件与社区能力。例如：
   - 图片、音频、视频等媒体文件
   - 各类组件与自定义展示
   - 脑图类插件
   - Excalidraw
   - PDF++ 的摘录截图与相关显示
   - 各类数学公式
   - 以及更多依赖 Obsidian 原生编辑 / 预览生态的内容
4. 因此，在 weave 里改卡、看卡，整体更接近「在 Obsidian 里写笔记、看笔记」，而不是跳进另一个陌生编辑环境。

>备注：卡片最终仍保存在 weave 的牌组数据中；变的是预览与编辑体验接了官方能力，所以生态兼容面更广。

## 编辑思维更偏 Markdown，题型由内容符号动态解析
weave 中没有单独切换的「问答题模板」「挖空题模板」「选择题模板」。题型不是先选模板再填空，而是根据卡片 Markdown 内容里的特定写法，在保存与预览时动态解析出来。

1. 编辑卡片时，更推荐按 Markdown 思路直接写内容。
2. 普通问答题：按正常 Markdown 写正面与背面等内容即可。
3. 挖空题：在问答题基础上，给需要遮住的部分加上高亮类 Markdown 符号后，保存并预览时会自动识别为挖空题。默认常见写法是 `==挖空内容==`，具体符号也可在插件设置中调整。
4. 选择题：同样按约定的 Markdown / 标记写法组织选项与答案，保存预览时会自动识别为选择题，无需先切换模板。
5. 学习界面会按解析结果，自动采用对应的显示与作答方式。例如挖空可「显示答案」或「输入作答」，选择题先选选项再「确认答案」。

>备注：这是符合 Obsidian Markdown 编辑思维的设计。你改的是内容写法，插件负责识别题型；不必在多个模板之间来回切换。三种题型的标准写法与医学示例，见 `We-01g 卡片题型`。

## 学习提示：沿用 Obsidian 官方脚注
记忆学习界面中的提示，遵循 Obsidian 官方脚注写法来实现，而不是另开一套提示字段。

1. 在卡片 Markdown 中按官方脚注格式书写即可。常见写法例如：正文里写 `[^1]`，文末写 `[^1]: 这里是提示内容`。
2. 学习预览时，可悬停脚注标记查看提示浮窗，也可点击脚注标记跳转到对应提示内容。
3. 提示与题目写在同一份 Markdown 里，编辑方式与 Obsidian 笔记中的脚注一致。

>备注：想在回忆卡住时给自己一点线索，直接用官方脚注加提示即可，不必额外学习另一套提示语法。

## 图片遮罩
该功能适用于医学图谱、解剖图等需要「挡住局部、先回忆再揭开」的图片卡。

1. 卡片中先放入图片。
2. 在编辑卡片时，将光标移到图片所在行，通过编辑器菜单中的「Weave 图片遮罩」，或命令面板中的「编辑图片遮罩」，为图片区域添加遮罩。
3. 也可在支持的图片文件上，通过右键菜单打开「Weave 图片遮罩」。
4. 进入记忆学习后，带遮罩的图片会先挡住对应区域；点击「显示答案」时会揭开遮罩。
5. 学习过程中也可点击单个遮罩，按需要单独揭开或盖回。

>备注：图片遮罩适合图谱定位、结构辨认这类场景；文字挖空仍优先用高亮符号，二者用途不同。

## 自动播放音频
该功能适用于单词卡等带发音的卡片，复习时可自动播放音频。

1. 卡片内容中包含音频（例如单词发音）时，可在记忆学习右侧「更多」里打开「自动播放媒体」。
2. 可选择播放时机：切换卡片时播放，或显示答案时播放。
3. 可选择播放范围：只播第一个，或全部播放。
4. 适合英文单词、发音跟读一类卡片；配合 fingertip translation 等途径加入的单词卡时尤其常用。

>备注：自动播放改的是听的时机，不替代评分。不想听时，关掉「自动播放媒体」即可。

## 学一张卡的基本流程
记忆学习的核心就是这个循环。

1. 先看当前卡片正面或题干，先自己回忆，不要急着点开答案。
2. 想好后，点击底部「显示答案」。选择题、以及挖空「输入作答」模式下，按钮文案可能是「确认答案」。
3. 答案揭开后，根据回忆情况点击四个评分之一：
   - 「重来」：没记住，很快会再回来。
   - 「困难」：勉强想起，但仍吃力。
   - 「良好」：正常记住，这是最常用的一档。
   - 「简单」：非常轻松，间隔会拉得更长。
4. 每个评分键上通常会显示预测间隔，例如几分钟或几天，便于判断选哪一档。
5. 评完后自动进入下一张，直到本场队列结束。

>备注：评分没有绝对标准。可先以「良好」为基准：明显更吃力就降到困难或重来，明显过轻松再升到简单。

## 揭开答案后的常用底栏操作
答案显示后，底部除了评分，还有两个常用操作。

1. 「返回预览」：先把答案收起来，只回到预览状态，不会把这张卡评掉。
2. 「撤销」：撤销上一次评分。若还有可撤销次数，按钮上会有提示。

>备注：返回预览适合答案看早了、想再回忆一次；撤销适合刚才按错评分键。

## 挖空题与选择题在学习时的差异
题型由内容解析而来后，学习底栏的第一步会略有不同。

1. 普通问答卡：通常点击「显示答案」后评分。
2. 选择题：先选择选项，再点「确认答案」，然后评分。
3. 挖空题可切换作答方式：
   - 「显示答案」：直接揭开挖空内容再评分。
   - 「输入作答」：先自己输入，再确认后评分。
4. 作答方式可在学习底栏或更多设置中按需要切换。

>备注：学习时不必先选模板。你在编辑里怎么写，学习里就按对应题型呈现。真正决定下次何时再见到这张卡的，仍是四个评分。

## 学习过程中修改当前卡
学到一半时，可直接处理当前这张卡，不必退出整场学习。

1. 「编辑」：打开官方编辑体验修改卡片 Markdown 内容；可继续使用你熟悉的 Obsidian 写法与兼容插件能力，改完可回到预览继续学。
2. 「提醒」：给当前卡设置复习提醒。
3. 「优先级」：调整为低、中、高、紧急等。
4. 「牌组」：调整当前卡的牌组归属。
5. 「查看」：打开更完整的卡片信息。
6. 「删除」：删除当前卡。若开启了直接删除，操作会更直接，请谨慎。

>备注：学习中的编辑、换牌组、改优先级，改的是这张卡本身；评分改的是这张卡接下来的复习安排。若通过加高亮等方式把问答改成挖空，保存预览后会按新内容重新识别题型。

## 回收卡片
该功能适用于暂时不想删，但又不想继续留在本场学习队列里的卡片。

1. 在更多设置中找到「回收卡片」。
2. 点击应用后，会给当前卡加上回收标签，并把它移出当前学习队列。
3. 回收标签支持 `#回收` 或 `#recycle`。
4. 卡片不会因此丢失。之后可在内容中去掉回收标签，再重新进入学习。

>备注：回收不是删除。删除会去掉卡片；回收只是暂时移出队列，方便以后再改、再学。

## 回到源文档
若卡片带有溯源信息，学习时可回到原文核对上下文。

1. 顶部可展开来源相关信息。
2. 通过源文档 / 源块相关入口，可跳转到笔记、pdf、epub 等来源位置。
3. 部分源块文本与高级溯源能力，可能属于高级功能。

>备注：复习卡面是主线；回原文是辅助。卡面回想不起来时，再去源文档核对通常更有效。

## 更多设置
右侧「更多」里，可调整本场学习的一些行为。

1. 自动播放媒体：是否自动播放卡片中的音频 / 视频，以及播放时机、播放第一个还是全部。详细说明见上文「自动播放音频」。
2. 卡片顺序：正序学习或乱序学习。
3. 选项顺序：选择题选项正序或乱序。
4. 显示学习计时：是否显示当前卡片用时等信息。
5. 超时暂停、显示内容标签、显示作答方式切换、启用直接删除等，也可在此按需开关。

>备注：这些设置影响学习体验，不替代评分。日常最常用的，仍是显示答案与四个评分键。

## 学完本场之后
当本场队列学完，会结束记忆学习界面，并回到牌组学习相关流程。

1. 若本场确实复习了卡片，通常会弹出学习成就结算窗。
2. 结算中可看到复习卡片数、新学卡片数、学习时长、记忆率等。
3. 点击「知道了」即可结束。
4. 若已有考试题组，也可从结算继续选择考试题组去做测验，但这不是记忆学习的必经步骤。

>备注：中途直接关掉学习界面，且还没有形成有效复习时，通常不会弹出结算。

## 今天学完了还能做什么
若点击牌组后提示今天已学完，或当前没有到期卡片，不代表牌组坏了。

1. 「今天已学完」：今天该牌组的学习额度或到期任务已经完成。
2. 「当前没有到期卡片」：牌组里有卡，但按安排还没到该复习的时候。
3. 「这个牌组还是空的」：还没有可学习的卡片，需要先制卡或导入。
4. 需要的话，可使用「提前学习」，或先去牌组分析查看数据，再决定要不要继续加新卡。

>备注：记忆学习按到期与限额推进，不是每次点开都能无限刷完整个牌组。想提前学，用牌组菜单里的提前学习。
