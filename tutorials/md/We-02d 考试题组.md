Weave Deck 的考试题组，适用于把已有选择题、可作答挖空题组织成题库，进行限时测验、错题回顾与正确率分析。题组本身主要保存题目引用与测试数据，卡片正文仍保存在记忆牌组中。适合刷题、模考、阶段测评，与偏间隔复习的「记忆牌组」形成互补。以下是详细介绍：

## 考试题组与记忆牌组的关系

理解两者分工，有助于选对入口、避免误删数据。

1. **记忆牌组**保存卡片正文、复习进度与牌组归属，适合日常记忆学习与 FSRS 复习。
    
2. **考试题组**保存题目索引、测试次数、正确率、错题本状态等考试向数据，适合组卷练习与统计分析。
    
3. 题组中的每道题，通常是对记忆牌组里某张卡片的**引用**，而不是单独复制一份正文。
    
4. 因此：**从考试题组移除**只会去掉题组记录与测试数据，记忆牌组里的卡片仍会保留；**删除卡片**则会从记忆牌组与考试题组中一并删除。
    

> 备注：记忆牌组偏「学会并记住」；考试题组偏「会不会、稳不稳」。两者可配合使用，例如先记忆复习，再进入题组模考。

## 进入考试题组模式

考试题组不是独立顶层页面，而是在「牌组学习」与「卡片管理」中通过数据源或筛选切换进入。

### 牌组学习界面

1. 打开插件主界面，进入「牌组学习」。
    
2. 通过顶部彩色圆点，从「记忆牌组」切换到「考试题组」。
    
3. 切换后，主内容区展示的是各个考试题组卡片，而不是记忆牌组卡片。
    
4. 左上角创建入口也会变为「创建考试题组」。
    

### 卡片管理界面

1. 打开插件主界面，进入「卡片管理」。
    
2. 通过左上角菜单或顶部数据源功能键，将数据源从「记忆牌组」切换为「考试题组」。
    
3. 切换后，表格、网格、看板中展示的是各题组下的题目卡片，而不是全部记忆卡。
    

> 备注：考试题组可能属于高级功能。若切换后提示需要开通，按插件提示处理即可。未激活时，界面可能显示「考试题组（高级）」。

## 创建与编辑考试题组

### 新建考试题组

1. 在「牌组学习」且处于「考试题组」筛选下，打开左上角菜单，选择「创建考试题组」。
    
2. 填写题组名称；可按需添加标签，用于后续分组与学习路线筛选。
    
3. 保存后，新题组会出现在牌组学习界面中。
    
4. 新建题组初始可能为空，需要再从卡片管理或其他入口把符合规则的题目加入其中。
    

### 编辑与删除

1. 在题组卡片上打开菜单，可选择「牌组编辑」或「编辑」。
    
2. 可修改题组名称、标签等信息；同一标签组内通常最多选一个标签，便于分列与筛选。
    
3. 删除题组前会要求确认；删除后题组数据无法恢复，但**不会自动删除**记忆牌组中的卡片正文。
    

> 备注：题组卡片外观样式（如「默认」「国风雅致」）跟随插件设置中的「牌组卡片样式」，与记忆牌组共用同一套视觉主题。

## 题目收录规则

并不是所有记忆卡都能进入考试题组，插件会按题型规则筛选。

1. **选择题**：可解析为选择题结构的卡片，可直接收录。
    
2. **挖空题**：只有内容中带 `#input` 标签的挖空题，才会被视为可作答填空题并收录。
    
3. 普通问答题、未带 `#input` 的挖空题、无法识别为选择题的内容，通常**不会**加入考试题组。
    
4. 批量加入时，若部分卡片不符合规则，界面可能提示跳过张数；符合规则的仍会正常入库。
    

> 备注：若希望某张挖空题进入考试题组，请先在卡片正文中加入 `#input` 标签。卡片题型规范见 `We-01g 卡片题型`。

## 如何把题目加入考试题组

### 从卡片管理批量加入

该路径最常用，适合已有大量选择题后集中组卷。

1. 在「卡片管理」中，先将数据源切回「记忆牌组」，找到并选中要收录的选择题或可作答挖空题。
    
2. 打开批量操作菜单，找到「被以下考试题组所引用」相关入口。
    
3. 选择已有考试题组，或新建一个考试题组。
    
4. 确认后，符合条件的卡片会被加入该题组；记忆牌组中的卡片正文保持不变。
    

### 组建考试题组

适合一边创建题组、一边把当前选中的卡片一并收录进去。

1. 在卡片管理中选中多张符合规则的卡片。
    
2. 通过批量菜单进入「组建考试题组」。
    
3. 填写题组名称与标签，确认创建。
    
4. 创建成功后，选中卡片会作为题目引用写入新题组。
    

### 从 AI 制卡导入时关联

在 AI 制卡预览区使用「立即学习 → 考试学习模式」筛选后入库，或在导入流程中指定考试题组时，插件会：

1. 先把保留的卡片写入记忆牌组；
    
2. 再将其中的选择题等可收录题目，关联到所选考试题组。
    

> 备注：AI 制卡流程详见 `We-01h AI制卡`。解析预览导入若指定考试题组，也遵循同一套「记忆牌组 + 题组引用」逻辑。

### 配对记忆牌组

若某个记忆牌组与某个考试题组成对使用，可在记忆牌组上建立配对关系。

1. 在记忆牌组的菜单中，选择「配对考题组」。
    
2. 从列表中选择目标考试题组；已配对的题组会有相应状态提示。
    
3. 配对后，从该记忆牌组发起考试时，可优先进入已配对的题组。
    

> 备注：题组树形展示会跟随记忆牌组层级组织，因此配对有助于让「学习牌组」与「考试题组」在结构上对应起来。

## 牌组学习界面中的题组管理

切换到「考试题组」后，牌组学习界面展示的是题组级卡片，而不是单题。

### 题组卡片信息

每个考试题组卡片上，通常可看到：

1. **总题**：题组内题目总数。
    
2. **已练**：至少做过一次测试的题目数。
    
3. **正确率**：基于测试数据的整体表现。
    
4. **累计错误**或错题相关统计。
    

### 开始考试

1. 点击题组卡片，或在其菜单中选择开始学习 / 开始考试。
    
2. 若该题组存在未完成的考试会话，可能先询问「恢复学习」「重新开始」或「取消」。
    
3. 若无未完成会话，会打开「考试模式配置」，确认后进入考试界面。
    
4. 空题组无法开考；空态通常会提示先到卡片管理中从选择题等引入题目。
    

### 题组分析与看板

1. 在题组卡片菜单中，可选择「分析」，查看该题组的掌握度趋势、EWMA 等考试向图表。
    
2. 在看板视图下，题组还可按正确率等维度分列，例如「未练习」「＞90 分」「＞75 分」「＜60 分」，便于找出薄弱题组。
    
3. 也可配合标签、标签组组织题组列，具体分列方式可在看板相关设置中调整。
    

> 备注：牌组学习页管理的是「题组入口」；单题正文与逐题测试数据，更适合到卡片管理的「考试题组」数据源里细查。

## 卡片管理中的考试题组视图

把卡片管理数据源切到「考试题组」后，看到的是**题目级**卡片列表。

### 视图与字段

1. **表格视图**会自动切换为题组专用字段预设，例如「极简」「考试」「全部」。
    
2. 相比记忆牌组，常多出 **考试题组**、**题型**、**正确率**、**测试次数**、**最后测试**、**错题等级** 等列。
    
3. **网格视图**仍支持固定布局、瀑布流、时间线等布局；可在卡片属性角标中显示正确率等信息。
    
4. **看板视图**默认常按「状态」分组，也可按题型、优先级、牌组、标签等维度组织题目。
    

### 考试题组专用搜索

在「考试题组」数据源下，顶部搜索除普通关键词外，还支持属性前缀，例如：

1. `type:`：按题型搜索。
    
2. `accuracy:`：按正确率搜索，如 high、medium、low 或具体数值。
    
3. `attempts:`：按测试次数搜索。
    
4. `error:`：按错题等级搜索，如高频、常见、轻度等。
    

> 备注：写法符合 Obsidian 的搜索设计。筛选后仍可在当前视图内批量移除题组引用、加标签或编辑题目。

## 开始考试与考试模式配置

每次正式开考前，都可以配置本场考试的题量、来源与规则。

### 第一步：核心配置

1. **题目数量**：如默认（全部）、20 题、30 题、50 题或全部。
    
2. **题目来源**：全部题目、未练习、错题本、已标记。
    
3. **时间限制**：不限时，或 15 / 30 / 60 分钟等。
    
4. 界面会显示 **预计题数** 与 **预计用时**，便于确认范围。
    

### 第二步：高级选项

1. **题型分布**：可调整单选题、多选题、填空题、简答题的比例。
    
2. **难度分布**：可调整简单、中等、困难比例。
    
3. **随机题目顺序**、**随机选项顺序**：打乱出题与选项顺序。
    
4. **自动保存进度**：中断后可恢复未完成会话。
    
5. **启用纯考试模式**：关闭功能栏与即时正误反馈；保留提交按钮，提交后直接进入下一题，更接近真实考场体验。
    

确认后点击 **开始考试**，配置会应用于当前场次。

> 备注：纯考试模式适合正式模考；日常刷题、想即时看解析时，可不启用该项。

## 考试学习界面

进入考试后，界面围绕「逐题作答 → 提交 → 下一题 → 交卷」展开。

### 头部与进度

1. 顶部显示当前进度，如 **学习进度 3 / 20**。
    
2. 若设置了限时，会显示剩余时间，并可暂停或继续倒计时；时间到后会自动交卷。
    
3. 可展开或收起统计区、题目导航、侧边工具栏。
    

### 答题与反馈

1. 选择题：选中选项后点击 **提交答案**；非纯考试模式下，可能即时显示「你选对了」「你选错了」「漏选」等反馈。
    
2. 填空题：在输入区作答后提交；系统会按规则判分或记录回答。
    
3. 简答题：可填写你的回答；若无自动判分标准，会记录回答并展示参考答案。
    
4. 提交后可查看 **答案解析**（纯考试模式下通常不即时展示）。
    
5. 底部按钮会在 **提交答案**、**下一题**、**完成测试** 之间切换；部分模式下支持 **撤销**。
    

### 题目导航与侧栏工具

1. **题目导航**以题号格展示当前题、已答对、已答错、未答等状态，可快速跳题。
    
2. 侧栏或垂直工具栏中，还可：
    
    - 编辑题目；
        
    - **从考试题组移除** 或 **删除卡片**；
        
    - 收藏 / 取消收藏；
        
    - 设置重要程度（低 / 中 / 高 / 极高）；
        
    - 调整题目顺序、选项顺序、导航列数；
        
    - 查看卡片信息与测试数据；
        
    - 在有溯源信息时定位到源文档、PDF、EPUB 或块引用位置。
        

> 备注：考试界面里的「删除卡片」会从记忆牌组与考试题组中彻底删除，不可撤销；若只想退出本次题组练习，应使用「从考试题组移除」。

## 考后结果与会话恢复

### 测试完成页

1. 完成全部题目或时间耗尽交卷后，会进入 **测试完成** 页面。
    
2. 通常展示 **得分**、**答对**、**用时**、**正确率** 等摘要。
    
3. 若已有多次测试记录，还可能显示历史趋势图，观察正确率或分数变化。
    

### 未完成会话

1. 若开启了自动保存进度，中途退出后再进入同一题组，可能提示存在未完成会话。
    
2. 可选择 **恢复学习** 继续上次进度，或 **重新开始** 清空本场进度重新作答。
    

> 备注：恢复的是「当前考试会话」进度，不会改写记忆牌组里的卡片正文。

## 从题组移除与彻底删除

这是最容易混淆的两类操作，建议按目的区分：

| 操作 | 适用场景 | 对记忆牌组的影响 |
|------|----------|------------------|
| 从考试题组移除 | 这题不再纳入本套题组练习 | 卡片正文保留 |
| 删除卡片 | 这题彻底不要了 | 卡片被删除 |

1. 在考试学习界面、卡片管理批量操作或题目菜单中，都可以执行「从考试题组移除」。
    
2. 移除后，该题在本题组内的测试数据、错题记录等会清除，但记忆牌组中仍可继续复习这张卡。
    
3. 若记忆牌组中的源卡片已被删除，而题组里仍残留引用，可在插件「数据管理」中检查并修复 **考试题组悬空引用**。
    

## 与记忆学习的衔接

考试题组并不孤立存在，插件会在多个节点把它和记忆学习连起来。

1. 记忆学习完成后，庆祝页底部可能出现 **选择考试题组**，便于刚复习完的内容马上转入测验。
    
2. 从记忆牌组上下文，可通过 **配对考题组** 快速找到对应题组。
    
3. 卡片管理表格中，**牌组** 列表示题目所属记忆牌组，**考试题组** 列表示它当前被哪些题组引用。
    

> 备注：若当前记忆牌组没有已配对的可用考题组，从记忆路径一键开考试时可能提示先完成配对或手动选择题组。

## 常见使用路径建议

可按学习阶段组合使用：

1. **先记忆、后测验**：在记忆牌组中制卡并复习，再把选择题批量加入考试题组，定期模考。
    
2. **边制卡、边组卷**：用 `We-01h AI制卡` 或 `We-01i 批量解析` 导入时，直接关联到目标考试题组。
    
3. **错题回炉**：在考试模式配置中选择「错题本」来源，集中重做错题。
    
4. **阶段测评**：启用限时与纯考试模式，模拟正式考试节奏。
