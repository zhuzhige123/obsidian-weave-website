Weave Deck 主界面中的 AI 制卡，适用于把一篇学习笔记交给大模型，自动拆成多张记忆卡片草稿。生成结果会先进入预览区，你可以逐张检查、挑选后再导入牌组。适合材料较长、需要理解与归纳后再制卡的场景。以下是详细介绍：

## 进入 AI 制卡界面

AI 制卡是插件主界面里的独立页面，与编辑器里「选中一段文字再制卡」不是同一个入口。

1. 打开插件主界面，通过左上角菜单切换到「AI 制卡」。
    
2. 进入后，页面上方是功能栏，中间是预览区，底部用于切换卡片、选择目标牌组并导入。
    
3. 若当前停在同一页的另一个子视图，请先切回「AI 制卡」。桌面端可通过左侧功能键切换；移动端也可通过顶部彩色圆点中的红点进入。
    

> 备注：本页专注于用大模型生成卡片。笔记已按固定版式写好、希望按规则直接拆分预览的情况，属于同一页面的另一套流程，不在本文范围内。

## 使用前准备

开始生成前，需要先完成 AI 服务配置，并准备好作为输入的 Markdown 笔记。

1. 打开插件设置，进入「AI 服务」相关配置，填写所用服务商的 API 密钥等信息。
    
2. 确认库中已有可作为源材料的 Markdown 笔记，且正文不为空。
    
3. 若尚未创建任何记忆牌组，建议先到「牌组学习」界面创建一个，便于后续导入。
    

> 备注：未配置 API 密钥时，「开始生成」会不可用或提示先去设置。这与「解析预览」是否需要解析模板，是两套不同的前置条件。

## 选择源笔记

AI 制卡以单篇 Markdown 笔记为输入，读取其正文后交给模型处理。

1. 点击顶栏「文件列表」，从库中搜索并选择一篇 Markdown 文件。
    
2. 选中后，功能栏会显示当前文件名；插件会记住你上次的选择，下次打开可继续沿用。
    
3. 若最近选择的文件已被移动或删除，界面可能提示文件不存在，重新选择即可。
    

> 备注：AI 制卡模式下选择的是「单篇笔记」，不是整文件夹批量读取。所选文件会作为卡片溯源文档记录，但通常不会精确到块级位置。

## 侧边栏模式与跟随当前文档

把 AI 制卡页放到 Obsidian 侧边栏时，选文件的方式会略有不同。

1. 将插件主界面拖到侧边栏后，界面会切换为更适合窄栏的布局。
    
2. 此时顶栏文件入口变为「跟随当前文档」开关，而不是直接弹出整库文件列表。
    
3. 开启后，你在中间内容区切换笔记、PDF、EPUB 等文件时，AI 制卡会自动跟随当前打开的 Markdown 作为源笔记。
    
4. 关闭跟随，则恢复为手动指定源文件的方式。
    

> 备注：跟随当前文档适合「边读边制卡」；需要固定某一篇长文反复生成时，更适合在主内容区手动选文件。

## AI 制卡配置

提示词、生成数量、题型比例等参数，集中在「AI 制卡配置」里设置。

1. 点击左上角菜单，选择「AI 制卡配置」。
    
2. 在「提示词」中，可选择内置系统提示词，或使用固定目录下的用户提示词文件；也可新建、编辑自定义提示词。
    
3. 在「制卡设置」中，可调整生成数量、难度级别、问答题 / 挖空题 / 选择题的比例，以及 Token 上限等高级选项。
    
4. 修改后点击「保存并应用」，配置会作用于下一次生成；插件也会记住你的常用设置。
    

> 备注：实际生成张数受配置中的数量上限约束，不一定等于源笔记段落数。题型分布总和需为 100%，否则无法保存。

## 选择模型并开始生成

配置完成后，在顶栏确认模型并发起生成。

1. 点击顶栏「AI 模型」，选择服务商与具体模型。
    
2. 确认源笔记已载入，且当前服务商已在设置中配置好 API 密钥。
    
3. 点击右上角「开始生成」。
    
4. 生成过程中，预览区会逐张追加卡片，并显示进度；顶栏按钮会变为「取消生成」，可随时中止。
    
5. 生成结束后，顶栏可能显示本次 Token 用量概况，便于了解消耗情况。
    

> 备注：若遇到限流、网络错误或余额不足，界面或通知会提示失败原因。可稍后重试、减少生成张数、更换模型，或检查 AI 服务配置。

## 预览与挑选卡片

生成完成后，先在预览区检查内容，再决定哪些卡片入库。

1. 主预览区展示当前卡片的正反面，可像正常学习卡片一样查看答案。
    
2. 底部序号条用于切换卡片；点按序号可跳转，长按序号可选中或取消选中。
    
3. 新生成的卡片默认处于选中状态；不需要的可在序号条上长按取消，或使用「全选 / 取消全选」。
    
4. 生成过程中已出来的卡片，也可以边生成边预览、边调整勾选范围。
    

> 备注：预览区改变的是「是否导入」，不会改写源笔记。若某张卡格式异常，导入时可能有提示或失败，可先取消勾选该张。

## 导入到牌组

确认无误后，将勾选的卡片写入目标牌组。

1. 在预览区底部选择「目标牌组」。
    
2. 确认右下角导入按钮上显示的数量，即为当前勾选张数。
    
3. 点击「导入 N 张」执行入库。
    
4. 成功后，界面会给出摘要提示；已导入的卡片会自动从待导入勾选里移除，方便继续处理剩余预览卡。
    

> 备注：导入前至少需勾选一张卡片，并选定有效牌组。若目标牌组不存在，请重新选择后再导入。

## 立即学习：先筛选再入库

若希望像复习一样逐张过一遍，再决定哪些 AI 卡片真正入库，可使用「立即学习」。

1. 生成完成后，在预览区底部点击「立即学习」。
    
2. 可选择「记忆学习模式」或「考试学习模式」：
    
    - 记忆模式：适合问答题、挖空题等常规记忆卡片。
        
    - 考试模式：适合从生成结果中筛选选择题，并可关联到考试题组。
        
3. 进入暂存学习界面后，逐张查看卡片；完成评分视为「保留」，删除卡片视为「丢弃」。
    
4. 全部处理完后，会进入汇总页，显示保留与丢弃的数量，并可选择是否将保留卡片正式导入牌组。
    
5. 若还想回头再看，可选择返回继续学习；若放弃入库，可选择不入库直接结束。
    

> 备注：「立即学习」适合生成张数较多、希望先练一遍再决定入库的场景。若你已对预览结果很有把握，也可跳过此步，直接在预览区勾选后导入。

## 历史记录

AI 制卡会保留最近若干次生成会话，便于恢复上下文。

1. 点击顶栏「历史记录」，可查看最近 5 次生成记录。
    
2. 每条记录通常包含源文件名、提示词文件与生成张数等信息。
    
3. 点击某条记录，可恢复该次的源内容、配置与预览结果，便于对比、补导入或重新挑选。
    
4. 无历史时，该入口可能呈空状态或不可用。
    

> 备注：历史记录保存在本地，只覆盖最近有限次数，不是无限云端备份。解析预览不以同一套 AI 生成历史为核心。

## 与编辑器制卡的区别

插件里还有「选中文本制卡」等编辑器侧能力，适合单段内容快速制卡。

1. AI 制卡主界面：面向整篇笔记，批量生成多张预览卡，再统一导入。
    
2. 编辑器划词 / 选段制卡：面向当前选中片段，流程更短，界面也不同。
    

> 备注：两者可以配合使用，例如先用 AI 制卡处理长文，再用选段制卡补充局部内容。卡片格式规范见 `We-01g 卡片题型`。
