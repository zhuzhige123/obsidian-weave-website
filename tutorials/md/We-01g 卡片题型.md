obsidian weave 中没有单独切换的「问答题模板」「挖空题模板」「选择题模板」。题型由卡片 Markdown 内容里的特定写法，在保存与预览时动态解析。以下说明常用题型与相关能力，并给出医学内容标准示例。

>备注：改写法即可改题型。学习界面里的呈现差异，可对照 `We-02c 记忆学习界面`。本教程里凡涉及挖空符号、Anki 编号挖空、单词标记等，一律放在代码块中展示，避免被 Dataview 等插件把双等号、双冒号当成查询语法误解析。

## 问答题
该题型适用于先看问题、再回忆答案的常规记忆卡。

1. 正面写题干，背面写答案；中间用 `---div---` 分隔。
2. 正面、背面都可使用 Obsidian 官方 Markdown，如图片、公式、列表、脚注等。
3. 保存并预览后，学习时先显示正面，点击「显示答案」后再看背面。

标准示例：

```markdown
二尖瓣位于哪个心腔之间？主要防止血液如何反流？

---div---

位于左心房与左心室之间。收缩期关闭，防止左心室血液反流回左心房。
```

![[QQ_1786423499965.png]]


再给一个带脚注提示的例子：

```markdown
简述急性心肌梗死最常见的病因。[^1]

---div---

冠状动脉粥样硬化斑块破裂，继发血栓形成，导致冠状动脉急性闭塞。

[^1]: 想一想：是血管本身的问题，还是心电传导的问题？
```

>备注：问答题是最基础的写法。后面挖空、选择都建立在 Markdown 内容之上，只是多了特定符号或选项结构。

## 选择题
该题型适用于单选或多选测验。写入约定结构后，保存预览时会自动识别为选择题，无需先切换模板。

1. 先写题干，再写 `A.` `B.` `C.` `D.` 等选项（也可用 `A、` 这类写法）。
2. 正确答案常见有两种标法：
   - 写在题干末尾括号里，例如 `（B）`、`（AC）`
   - 或在背面写 Answer 行，例如下方代码块中的写法
3. 可用 `---div---` 分隔解析。背面可写解析说明。
4. 学习时先选选项，再点「确认答案」，然后评分。

单选标准示例：

```markdown
关于成人心肺复苏（CPR），下列哪项正确？（B）

A. 胸外按压部位为胸骨中上 1/3 交界处
B. 胸外按压部位为胸骨下 1/2，两乳头连线中点
C. 按压深度成人约为 2–3 cm
D. 按压与通气比固定为 15:2

---div---

成人按压部位为胸骨下 1/2（两乳头连线中点附近）；深度通常约 5–6 cm；单人施救时按压与通气比常为 30:2。
```

![[QQ_1786423548856.png]]
多选标准示例：

```markdown
下列哪些属于急性阑尾炎较常见的临床表现？

A. 转移性右下腹痛
B. 右下腹压痛、反跳痛
C. 大量血便伴里急后重
D. 可伴恶心、呕吐、低热

---div---

Answer: A,B,D
典型为转移性右下腹痛，并出现右下腹压痛与反跳痛；恶心、呕吐、低热也可出现。大量血便伴里急后重更提示下消化道其他病变，不是急性阑尾炎的典型表现。
```

>备注：至少需要题干和两个以上选项，才会按选择题解析。答案建议明确写出，便于学习时自动核对。 ^we-q-we-s74v3v

## 挖空题
该题型适用于在一段医学表述中遮住关键词，先回忆再揭开。默认用 Obsidian 高亮写法：用一对双等号包裹要遮住的词。也兼容 Anki 风格编号挖空。具体符号可在插件设置中调整。

1. 像写笔记一样写完整句子或段落。
2. 给需要遮住的词加上一对双等号。
3. 一张卡可有多处挖空。
4. 仍可用 `---div---` 写补充说明或解析；学习时主要按挖空揭开。
5. 学习时可「显示答案」直接揭开，或切换为「输入作答」。

标准示例：

```markdown
胰岛素由胰腺的 ==胰岛 β 细胞== 分泌，主要作用是 ==降低血糖==。
```

![[QQ_1786423613711.png]]
带解析的示例：

```markdown
慢性阻塞性肺疾病（COPD）的特征性病理生理改变是 ==不完全可逆的气流受限==。

---div---

诊断常结合吸烟史、慢性咳嗽咳痰，以及肺功能检查中支气管舒张试验后 FEV1/FVC < 0.70。
```

多处挖空示例：

```markdown
肾单位包括 ==肾小球==、==肾小管== 等结构。原尿在 ==肾小管== 被重吸收后，最终形成尿液排出。
```

>备注：挖空题不需要先选模板。在原有问答内容上给关键词加高亮，保存预览后就会按挖空题显示。医学名词、机制关键词、剂量单位等，都很适合做成挖空。

## 渐进式挖空
该题型适用于同一段内容里有多处挖空，希望拆成多张子卡、逐个练习，而不是一次同时揭开全部。

1. 使用 Anki 兼容的编号挖空写法：同一段里写 c1、c2、c3……多个编号。
2. 编号从 1 起，建议连续。两处及以上编号挖空时，weave 可按渐进式挖空处理并生成对应子卡。
3. 学习时每次主要练其中一个挖空，其它位置按规则显示，降低互相干扰。
4. 适合解剖路径、生理机制、药名剂量等「同一语境、多个要点」的记忆。

标准示例：

```markdown
肺循环的基本路径：
右心室泵血进入 {{c1::肺动脉}}，在肺部完成气体交换后，经 {{c2::肺静脉}} 回流至 {{c3::左心房}}。
```

带提示的示例：

```markdown
肾小球滤过膜由内向外依次为：
{{c1::内皮细胞::血管侧}}、
{{c2::基底膜}}、
{{c3::足细胞裂孔膜::尿囊侧}}。
```

>备注：普通挖空（双等号）适合一处或同屏一起练；渐进式挖空适合多编号、拆开练。日常 AI 批量制卡更常产出普通挖空；若要渐进式，需明确使用编号挖空写法。 ^we-q-we-ufhtlv

## 单词卡片
该类型适用于英文单词、医学英文术语等发音与释义记忆，常配合 fingertip translation 等取词流程加入 weave。

1. 在 Obsidian 插件市场安装 fingertip translation。
2. 选中文本取词后，在查询浮窗中选择添加到 weave，并指定牌组。
3. 卡片内容会带上单词相关标记与释义结构，学习时可配合自动播放发音。
4. 美音 / 英音等默认选择，优先跟随 fingertip translation 插件设置。
5. 也可在记忆学习界面「更多」中打开自动播放媒体，切换卡片或显示答案时自动播放发音。

内容结构示意（由添加流程生成，一般不必手写）：

```markdown
myocardial infarction

---div---

::fingertip::myocardial infarction::
/ˌmaɪ.əʊˈkɑː.di.əl ɪnˈfɑːk.ʃən/
心肌梗死；心肌梗塞
```

>备注：更完整的添加步骤见 `We-01a 新建卡片`。学习时的自动播放说明见 `We-02c 记忆学习界面`。

## 图片遮罩
该能力适用于医学图谱、解剖图、结构图等需要「挡住局部、先回忆再揭开」的场景。

1. 卡片中先放入图片。
2. 编辑时将光标移到图片所在行，通过编辑器菜单「Weave 图片遮罩」，或命令面板「编辑图片遮罩」，为图片区域添加遮罩。
3. 也可在支持的图片文件上，通过右键菜单打开「Weave 图片遮罩」。
4. 进入记忆学习后，带遮罩的图片会先挡住对应区域；点击「显示答案」时会揭开。
5. 学习过程中也可点击单个遮罩，按需要单独揭开或盖回。

>备注：图片遮罩适合图谱定位、结构辨认；文字挖空仍优先用高亮或编号挖空。二者可按场景分开用，也可出现在同一张含图卡片上。学习侧说明也可对照 `We-02c 记忆学习界面`。

## 卡片内容还可这样用
因为卡片预览与编辑沿用 Obsidian 官方能力，除上述题型外，还常配合社区插件做更细的材料呈现与溯源。

1. Excalidraw：支持局部绘图在卡片中渲染显示，并可溯源定位跳转到对应绘图区域。适合解剖示意图、机制手绘、手术步骤草图等。
2. 视频时间戳：支持带时间戳的视频笔记卡片；复习时可跳到对应时间点，反复听某一片段。适合英语跟听、手术示教录像、课堂讲解回放等。常配合 Media Extended 等媒体扩展类插件使用。
3. 此外还可配合 PDF++ 摘录截图与溯源、脑图、公式、各类组件等。未安装对应插件时，不影响 weave 主路径的 Markdown 制卡与复习。

>备注：weave 负责记忆与检验；具体阅读、绘图、视频现场尽量复用 Obsidian 生态。材料进了卡片后，学习时仍可跳回原文上下文。

## 怎么选
按记忆目的选写法即可。

1. 要完整表述一个概念、机制、处理原则：用问答题。
2. 要在易混选项里做判断：用选择题。
3. 要在原文语境里记住关键名词或关键词：用普通挖空。
4. 同一段有多处要点、希望拆开逐个练：用渐进式挖空。
5. 英文单词 / 术语发音与释义：用单词卡片流程。
6. 图谱局部辨认：用图片遮罩。
7. 手绘结构、视频片段：用 Excalidraw 或视频时间戳相关写法，并保证对应社区插件可用。

>备注：题型与能力由内容写法与生态插件共同决定。你改的是 Markdown 与材料引用，weave 负责识别题型，并在预览、学习中按对应方式呈现。
